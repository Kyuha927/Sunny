## 읽는 순서

1. Quick Guide로 전체 흐름을 잡는다.
2. Graph로 연결 구조를 본다.
3. Projects에서 실제 작업축을 확인한다.
4. References에서 기준 문서를 확인한다.
5. Agent Notes에서 운영 메모를 누적한다.
6. Daily Logs Index에서 날짜별 기록을 찾는다.

## 분류 기준

- `Projects`: 지금 실제로 움직이는 작업과 저장소
- `References`: 기준 문서, 규칙, 체크리스트
- `Agent Notes`: 운영 메모, 요약, 회고, 재진입용 노트
- `Templates`: 반복 작성용 서식
- `Daily Logs`: 날짜별 누적 기록
- `Weekly Review`: 주간 회고 누적
- `Project Status`: 프로젝트 상태 한 장 요약
- `Archive Index`: 정리된 노트의 목록
- `Obsidian Plugins`: vault 설정과 플러그인 구성
- `Inbox`: 새 메모의 임시 수집지
- `Archive`: 끝난 메모의 보관함

## 운영 원칙

- 한 노트에 다 넣지 않는다.
- 기준과 메모를 분리한다.
- 실행 결과는 짧게, 판단 근거는 링크로 남긴다.
- 새로 생긴 노트는 이 MOC에서 먼저 연결한다.
