## 한 줄 구조

- `msw2`는 기준 문서 저장소다.
- `antigravity_bridge`는 세션 결과를 파일로 남기는 실행층이다.
- `antigravity_brains`는 기억과 복구 기록을 누적하는 장기 메모리층이다.
- `Sunny` vault는 Obsidian에서 이 구조를 담는 상위 컨테이너다.

## 작업할 때의 순서

1. SSOT를 먼저 확인한다.
2. 작업 결과를 세션 파일이나 노트로 남긴다.
3. 기억할 내용은 브레인/색인 문서에 누적한다.
4. 모호하면 `OpenQuestions.md`를 먼저 보고, 필요하면 MCP 도구로 확정한다.

## 핵심 규칙

- 서버 권한이 최우선이다.
- Sync는 최소화한다.
- 무거운 로직은 tick으로 분리한다.
- 세션 결과는 GUI가 아니라 파일에 남긴다.
