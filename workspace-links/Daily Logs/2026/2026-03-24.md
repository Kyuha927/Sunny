# 일일 회고 — 2026년 3월 24일

## 오늘 상태
- 작성: 3월 24일 밤 11시

## 오늘 한 일

**1. 미연시 — 세션 날아가는 문제 해결**
작업하다가 대화방이 바뀌면 그동안 한 게 싹 사라지는 문제가 계속 있었다. 진짜 미치는 줄 알았는데, 오늘 "이 문서 하나만 보면 현재 상태 다 파악 가능한" 기준 문서를 하나 만들어서 박아넣었다. 이제 대화방이 날아가도 작업 내역이 증발하지 않는다.

**2. 미연시 — 1장 영상 자동화**
비 오는 역 배경 그림을 움직이는 영상으로 변환하는 작업을 자동으로 돌아가게 세팅했다. 수동으로 하나하나 넣던 걸 이제 한 번에 돌린다.

**3. 작업 분배**
오늘 총 6건을 다른 에이전트들한테 나눠서 시켰다.
- 유니티 배경음악 붙이기
- 음성 합성 연동
- 그림 에셋 1차 확인
- 영상 생성 로직 정리
- 캐릭터 영상통화 앱 다음 단계 설계

솔직히 이렇게 여러 건을 한꺼번에 돌리니까 좀 정신없긴 했다.

**4. 가상 스튜디오 구조 만들기**
여러 에이전트들한테 역할을 나눠서 조직처럼 묶는 구조를 짰다. 이전엔 그때그때 하나씩 불러서 시켰는데, 이제 누가 뭘 맡고 있는지가 한눈에 보인다.

## 막히는 것
- 그림을 영상으로 바꾸는 데 시간이 꽤 걸린다. 분량이 늘어나면 여기서 막힐 수 있다.
- 인계 문서가 하루에 6개씩 쌓이는데, 이대로 가면 나중에 뒤죽박죽될 것 같다. 정리 방법을 고민해야 한다.

## 내일 할 것
- 가상 스튜디오 구조가 실제로 잘 굴러가는지 테스트.
- 음성 합성 결과물이 캐릭터 입 모양이랑 맞는지 확인.
- 1장 영상 결과물 퀄리티 점검.

## 회고

### 잘 된 것
일을 쪼개서 여러 에이전트한테 동시에 시키는 흐름이 드디어 돌아가기 시작했다. 무엇보다 기준 문서 하나 만들어놓은 게 가장 큰 성과인데, 이게 없었으면 오늘도 또 "어디까지 했더라?" 하면서 시간 날릴 뻔했다.

### 아쉬운 것
자동으로 시켜놓고도 결국 결과물은 내가 직접 확인해야 한다. 완전히 손 떼려면 에이전트한테 주는 지시를 더 꼼꼼하게 짜야 하는데, 그걸 다듬을 시간이 부족했다.

### 배운 것
에이전트를 하나씩 따로 부르는 것보다, 조직처럼 역할을 묶어버리는 게 훨씬 관리하기 편하다. 명령을 잘 내리는 것보다 구조를 잘 짜는 게 결국 더 세다.

### 다음에 바꿀 것
코드 한 줄 한 줄 들여다보는 습관을 좀 줄이고, 완성된 결과물 단위로 확인하는 쪽으로 바꿔야겠다. 세세하게 파고들다 보면 정작 전체 진행이 느려진다.
