# Project Shortcuts

이 폴더는 “이름만 보고 이해되는” 프로젝트 바로가기 모음입니다.
실제 원본 경로는 유지하고, 여기서는 의미 중심 이름으로만 보여줍니다.

## Naming Rules

- 형식: `{영역번호}_{도메인}_{핵심목적}`
- 예시:
  - `01_game_msw_core`
  - `11_agent_brain_rnd`
  - `21_prompt_copilot_library`
