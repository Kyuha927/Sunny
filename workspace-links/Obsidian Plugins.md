# Obsidian Plugins

이 노트는 현재 vault에서 확인된 Obsidian 플러그인 구성을 정리한다.

## Core Plugins

### Enabled

- file-explorer
- global-search
- switcher
- graph
- backlink
- canvas
- outgoing-link
- tag-pane
- properties
- page-preview
- daily-notes
- templates
- note-composer
- command-palette
- editor-status
- bookmarks
- outline
- word-count
- file-recovery
- sync
- bases

### Disabled

- footnotes
- slash-command
- markdown-importer
- zk-prefixer
- random-note
- slides
- audio-recorder
- workspaces
- publish
- webviewer

## Community Plugins

- obsidian-importer
- dataview
- copilot
- smart-connections
- vault-ai
- obsidian-git

## What This Suggests

- `daily-notes` and `templates` support a log-driven vault.
- `graph` and `backlink` support MOC-style navigation.
- `dataview` supports structured indexes and status pages.
- `obsidian-git` supports versioned note workflows.
- `vault-ai`, `copilot`, and `smart-connections` suggest the vault is intended for AI-assisted workflows.
