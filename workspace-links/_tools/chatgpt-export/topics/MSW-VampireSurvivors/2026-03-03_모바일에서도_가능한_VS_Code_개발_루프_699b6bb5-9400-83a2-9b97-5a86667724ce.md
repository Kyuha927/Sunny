## 1. assistant

휴대폰/태블릿에서 “진짜 쓸만한” 코딩·게임개발 워크플로를 한눈에 정리했어요.  

---

### 핵심 결론
- **가장 마찰이 낮은 방법**: 브라우저에서 돌리는 VS Code UI → **GitHub Codespaces** 또는 **self‑hosted code‑server(=VS Code 서버)**, 혹은 **vscode.dev**로 레포 간단 수정.  
- **터미널/깃 작업**: **SSH 클라이언트(Blink, Termius, Termux)** + **블루투스 키보드** 조합이 사실상 필수.  
- **무거운 에디터 작업(예: Unity Editor·에셋 임포트·빌드)**: 지연시간 때문에 **원격 데스크톱(Windows RDP, RustDesk, Parsec 등) + 고사양 원격 머신**이 현실적.  
- 모바일은 **스크립트 소규모 수정, 커밋, CI 트리거**까지는 훌륭하지만, **프로젝트 빌드/실행**은 권장하지 않음.

---

### 추천 세팅(빠르게 시작)
1) **브라우저 편집(선호)**  
- GitHub Codespaces 사용 → 레포 열기 → 브라우저 VS Code에서 바로 코딩.  
- 자기 서버가 있다면 `code-server`(VS Code 웹) 띄워서 접속.

2) **터미널·깃**  
- iOS: Blink / Termius, Android: Termius / Termux 설치 → `ssh user@host`.  
- 키보드 단축키가 생산성의 절반이라 **BT 키보드** 꼭 연결.

3) **원격 데스크톱(무거운 툴)**  
- Unity/언리얼 편집·에셋 임포트·플레이는 **원격 GPU 머신**에 설치 → 모바일에선 RDP/RustDesk/Parsec로 화면만 전송.

---

### 보안·신뢰성 체크리스트
- **외부 노출 금지**: code‑server 같은 웹 IDE는 가급적 **공개 인터넷에 직접 노출하지 않기**.  
- **접속 경로**: **프라이빗 터널(Tailscale/ZeroTier/와이어가드) + SSH 포트포워딩** 우선.  
- **인증/암호화**: **TLS(HTTPS) + 토큰/패스워드 + SSH 키**. 기본 비번은 즉시 변경.  
- **호스티드 선택지**: 설정 부담을 줄이려면 **Codespaces**를 우선 고려(비용·레포 제한 감수).

---

### 상황별 미니 가이드
- **“지하철에서 급히 버그만”**: vscode.dev로 파일 몇 개 수정 → 브랜치 푸시.  
- **“로그 보고 빠르게 핫픽스”**: SSH 접속 → `git pull && nano/vi` → 커밋/푸시 → CI 확인.  
- **“씬 편집·대용량 임포트”**: 원격 데스크톱으로 원격 워크스테이션 접속해 처리.

---

### 작은 팁
- 에디터 단축키 맵을 모바일 키보드에 익숙해지도록 **필수 단축키(복붙/멀티커서/파일 탐색)** 위주로 연습.  
- CI 파이프라인에 **테스트·빌드·배포**를 몰아 넣고, 모바일에서는 **트리거/모니터링**만.

---

필요하시면: iOS/Android별 앱 추천(SSH·RDP·파일 전송), code‑server 보안 설정 예시, Codespaces 비용 최적화 팁까지 바로 정리해 드릴게요.
