## 1. assistant

게임용 타일 아틀라스/맵 파이프라인을 **한 번 세팅하면 계속 재현 가능한 방식**으로 만드는 레시피를 정리했어요—CLI 예시, Tiled JSON 내보내기, 그리고 바로 붙여 쓰는 파랄락스(패럴랙스) 테이블까지.

# 왜 필요한가?
- 빌드마다 타일 인덱스가 바뀌면(트리밍·회전·패딩 등) 맵이 깨집니다.  
- 파랄락스가 서브픽셀로 흔들리면 레트로 픽셀 게임에서 화면이 “지직”합니다.  
아래 설정들은 이런 재작업을 없애는 **결정론적(deterministic)** 규칙들입니다.

---

## A) TexturePacker: “항상 같은 결과”를 뽑는 CLI
타일 세트 폴더를 안정적인 JSON 아틀라스로 패킹:
```bash
TexturePacker \
  --data out/tiles.json \
  --format json \
  --sheet out/tiles.png \
  --trim-mode None \
  --border-padding 0 \
  --shape-padding 0 \
  assets/tiles/*
```
**팁**
- CI에서 TexturePacker **버전 고정**.
- 타일 일치성 위해 **트리밍/오토회전 끄기**.
- **패딩 0**으로 인덱스 변동 방지(타일이 전부 동일 크기라는 전제).

---

## B) Tiled: 엔진 불문 JSON 내보내기
헤드리스/GUI 모두 가능:
```bash
# 헤드리스
tiled --export-map map.tmx map.json
# GUI: File → Export As → JSON
```
**중요 필드**  
`tilewidth`, `tileheight`, `columns`, 그리고 타일셋의 `margin`, `spacing`을 **명시적으로** 유지하세요.  
로더에서 `gid -> 아틀라스 프레임` 매핑이 **항상 동일**해집니다.

---

## C) 파랄락스(패럴랙스) 미니 레시피 (카메라 코드에 바로 삽입)
원리: 각 레이어에 **depth d(>0)** 부여 → `parallaxFactor = 1.0 / d`  
레이어 오프셋 = `cameraX * parallaxFactor`

| LayerName           | depth | factor(1/d) | 스냅 규칙                   |
|---------------------|:-----:|:-----------:|-----------------------------|
| foreground-tiles    |  1    |   1.0       | 1px 스냅                    |
| midground-near      | 1.5   |   0.6667    | 0.5px 스냅 또는 최종 반올림 |
| midground-far       | 2.5   |   0.4       | 반올림(정수 픽셀)           |
| background-clouds   |  4    |   0.25      | 서브픽셀 없음(타일 랩)      |
| sky-horizon         |  8    |   0.125     | UV 스크롤만                 |

**픽셀 퍼펙트 규칙**
1) 각 파랄락스 타일 랩 너비 ≥ `cameraWidth + tileWidth`.  
2) `offset = round(cameraDelta * parallaxFactor)`로 **최종 정수 반올림** 후 적용(서브픽셀 블러 방지).  
3) 렌더러가 카메라 라운딩을 한다면, **레이어도 동일한 라운딩**을 적용.  
4) 아틀라스는 **트리밍/회전 끄고, 입력 정렬 고정**(위 TexturePacker 플래그)으로 인덱스 불변.

---

## D) 최소 파이프라인(예: CI 단계)
1) (선택) 모든 `art/*.png`에 팔레트 리맵 등 **전처리** 수행.  
2) 위 TexturePacker CLI로 **tiles.json/tiles.png** 생성 → 아티팩트 업로드 또는 커밋.  
3) Tiled에서 `maps/*.json` 내보내기.  
4) 엔진 로더에서 **Tiled GID → 아틀라스 프레임**을 `tilewidth/columns` 기반으로 매핑.  
5) 카메라 갱신 시 파랄락스 레이어에 `round(cameraDelta * 1/d)` 적용.
