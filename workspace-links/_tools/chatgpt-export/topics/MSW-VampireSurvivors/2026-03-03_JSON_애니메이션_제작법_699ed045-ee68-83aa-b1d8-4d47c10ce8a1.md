“JSON으로 애니메이션”은 보통 아래 3가지 중 하나를 뜻해요. 가장 흔한 건 **Lottie(Bodymovin) JSON**입니다.

## 1) Lottie(JSON)로 애니메이션 만들기 (가장 많이 씀)
**용도:** 앱/웹에서 가벼운 벡터 애니메이션(아이콘, 로딩, 마이크로 인터랙션)

### 제작 흐름
1. **After Effects**에서 벡터 기반으로 애니메이션 제작  
   - Shape Layer(도형), Text, Position/Scale/Rotation/Opacity 위주로 작업
2. **Bodymovin 플러그인**으로 **.json 내보내기**
3. 웹/앱에서 Lottie 플레이어로 재생

### 웹에서 재생 예시
```html
<div id="anim" style="width:200px;height:200px"></div>
<script src="https://unpkg.com/lottie-web/build/player/lottie.min.js"></script>
<script>
  lottie.loadAnimation({
    container: document.getElementById('anim'),
    renderer: 'svg',
    loop: true,
    autoplay: true,
    path: './animation.json'
  });
</script>
```

## 2) JSON 스프라이트 시트로 애니메이션 만들기 (게임에서 흔함)
**용도:** 픽셀아트/2D 게임(프레임 애니메이션)

### 개념
- PNG 한 장(스프라이트 시트) + 프레임 좌표/시간 정보를 **JSON**에 저장
- 엔진(Phaser, PixiJS, Unity 등)이 JSON을 읽어 프레임을 바꿔가며 재생

### JSON 예시(TexturePacker 스타일)
```json
{
  "frames": {
    "run_0.png": { "frame": { "x": 0, "y": 0, "w": 32, "h": 32 } },
    "run_1.png": { "frame": { "x": 32, "y": 0, "w": 32, "h": 32 } }
  },
  "meta": { "image": "sheet.png" }
}
```

---

## 3) 웹 애니메이션을 JSON으로 “정의”하기 (커스텀)
**용도:** “키프레임/트윈”을 데이터로 저장하고 런타임에서 해석

### JSON 예시(키프레임)
```json
{
  "durationMs": 800,
  "tracks": [
    { "target": "#box", "prop": "transform.x",
      "keys": [[0, 0], [400, 120], [800, 0]] }
  ]
}
```
이걸 JS에서 읽어서 requestAnimationFrame으로 보간(interpolation)하면 애니메이션이 됩니다.
