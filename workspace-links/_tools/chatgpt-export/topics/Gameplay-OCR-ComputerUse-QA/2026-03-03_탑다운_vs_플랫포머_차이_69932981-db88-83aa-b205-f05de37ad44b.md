# ⚔️ 핵심 차이 정리

| 구분 | 탑다운 | 플랫포머 |
|------|--------|----------|
| 시점 | 위에서 아래 | 옆에서 측면 |
| 점프 | 거의 없음 | 핵심 시스템 |
| 중력 | 없음 or 약함 | 필수 |
| 레벨 설계 | 맵 구조 중심 | 발판 구조 중심 |
| 전투 | 공간 컨트롤 | 타이밍 + 위치 |
