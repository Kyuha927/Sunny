# 왜 연결하나요?
- 노트 생성/리팩터링/링킹을 에이전트가 대신 수행  
- 회의/브라우징 결과를 바로 볼트에 떨어뜨림(수작업 복붙 X)  
- “노트 → 작업 → 다시 노트” 루프가 자동화

---

# 빠른 설정 레시피(가장 쉬운 경로)

## 1) 공유 폴더를 볼트에 마운트
아래 둘 중 하나만 하면 됩니다.

### A. 볼트 안에 ‘받침대’ 폴더 만들기
- 예시 경로: `~/Obsidian/VaultName/antigravity-inbox`  
- Antigravity의 **workspace output** 경로를 위 폴더로 지정  
  - 이렇게 하면 에이전트가 만든 파일이 곧바로 볼트에 나타나요.

### B. 심볼릭 링크로 연결(에이전트 → 볼트)
- macOS/Linux
```bash
ln -s /Users/you/antigravity/workspaces/project/shared \
      /Users/you/Obsidian/VaultName/antigravity-shared
```
- Windows(관리자 PowerShell)
```powershell
mklink /D C:\Users\you\Obsidian\VaultName\antigravity-shared `
         C:\Users\you\antigravity\workspaces\project\shared
```

---

## 2) Obsidian 로컬 REST API 열기
- 커뮤니티 플러그인 중 “Local REST API”(또는 동등 기능)를 설치/활성화  
- 토큰(또는 포트/호스트)을 메모해둡니다.  
  - 목적: 에이전트가 HTTP로 노트 읽기·검색·쓰기 가능

---

## 3) 로컬 MCP 서버 실행
> MCP(Model Context Protocol)는 에이전트가 도구(플러그인/로컬앱)에 접속하는 표준입니다.

- 예시 서버:
  - `MarkusPfundstein/mcp-obsidian`
  - `lee3604/obsidian-local-mcp`
- 서버를 실행하면 “Obsidian=노트 툴”이 MCP로 노출됩니다.

---

## 4) Antigravity에 MCP 서버 등록
- `mcp.json`(또는 워크스페이스 MCP 설정)에 Obsidian MCP 서버를 추가:
```json
{
  "servers": {
    "obsidian": {
      "command": "node",
      "args": ["/path/to/obsidian-mcp/server.js"],
      "env": {
        "OBSIDIAN_API_URL": "http://127.0.0.1:27123",
        "OBSIDIAN_API_TOKEN": "your_api_token"
      }
    }
  }
}
```
- Antigravity를 재시작하면 `obsidian` 도구가 자동으로 발견됩니다.

- “오늘 회의 녹취 요약을 `Daily/2026-02-23.md`에 섹션으로 붙이고, TODO를 `Tasks/Inbox.md`에 체크박스로 정리해.”

# 보안/안전 체크
- 로컬 REST API 토큰 필수, 포트 방화벽 제한 권장  
- 에이전트가 쓸 수 있는 폴더를 제한(드롭존만 쓰게)  
- 커밋 전에 diff 확인(에이전트가 대량 수정하지 않도록 가드)
