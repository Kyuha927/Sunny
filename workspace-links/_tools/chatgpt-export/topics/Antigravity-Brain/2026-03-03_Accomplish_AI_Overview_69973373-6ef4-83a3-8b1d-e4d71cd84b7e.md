## 🧠 Accomplish란?

**Accomplish**는 로컬(내 PC)에서 실행되는 **오픈소스 AI 데스크톱 에이전트**입니다.  
단순 채팅이 아니라, 실제로 **파일을 읽고·정리하고·문서를 만들고·브라우저 작업을 수행하는 등 “행동”을 하는 AI 비서**입니다.

---

## 🛠 주요 기능

### 1️⃣ 실제 업무 자동화
- 폴더 정리
- 문서 생성 및 수정
- 파일 요약
- 웹 리서치
- 반복 작업 자동화

### 2️⃣ 로컬 실행 (Privacy 중심)
- Mac / Windows에서 직접 실행
- 파일은 기본적으로 **내 컴퓨터 안에서만 처리**
- 외부 전송 없이 사용 가능 (설정에 따라 다름)

### 3️⃣ 원하는 AI 모델 사용 가능
- OpenAI
- Claude (Anthropic)
- Gemini
- xAI
- Ollama(로컬 LLM)

👉 **내 API 키를 직접 연결해서 사용**하는 구조

### 4️⃣ 행동 전 승인 시스템
AI가 어떤 작업을 실행하기 전에  
**“이 작업을 실행해도 될까요?”** 하고 보여주고 사용자가 승인해야 실행됩니다.

### 5️⃣ 오픈소스 (MIT 라이선스)
- 코드 공개
- 직접 수정 가능
- 확장 가능

---

## 📦 사용 흐름

1. 프로그램 설치
2. AI API 키 연결 (또는 로컬 모델 사용)
3. 접근 허용할 폴더 지정
4. 자연어로 작업 지시

예:
- “이 폴더 정리해줘”
- “이 PDF 요약해줘”
- “이 자료 기반으로 보고서 만들어줘”
