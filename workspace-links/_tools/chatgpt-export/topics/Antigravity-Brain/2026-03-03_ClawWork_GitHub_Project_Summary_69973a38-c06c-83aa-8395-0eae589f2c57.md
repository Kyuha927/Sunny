## 📦 ClawWork 개요

**ClawWork**는 오픈소스 프로젝트로, 기본적으로 AI *어시스턴트*를 **“AI 동료(코워커)”**로 전환해 실제 경제적 가치가 있는 일을 수행하게 하는 시스템입니다. citeturn0search1

이 리포지토리는 **HKU Data Science Lab**(홍콩대 데이터 사이언스 연구실)에서 개발했으며, 기본 목표는 다음과 같습니다: citeturn0search1

- AI 모델을 단순한 도구가 아니라 **실제 작업을 수행하고 수익을 창출하는 에이전트**로 만들기  
- AI가 “경제 활동”을 통해 토큰 비용을 스스로 벌어가며 살아남도록 설계  
- GDP 수준의 직업 업무를 에이전트에게 할당해 **전문 업무 능력**을 평가

---

## 💡 주요 기능

### 📊 경제 기반 벤치마크  
- AI 에이전트는 **초기 자본($10)**으로 시작  
- 작업을 수행해 **토큰 비용을 지불하면서 돈을 벌어야 함**  
- 수익, 비용, 품질 등을 기반으로 생존 및 성과를 평가 citeturn0search1

### 🧠 전문 업무 과제  
- **OpenAI의 GDPVal** 데이터셋 기반으로 44개 산업의 실제 *전문 업무(tasks)*를 수행  
- 예: 데이터 분석 리포트, 엑셀/워드 문서 생성, 리서치, 기술 설명 등 citeturn0view0

### 🛠 멀티 에이전트 & 경쟁  
- 다양한 LLM (GPT, Claude, Qwen 등) 비교/경쟁 가능  
- “AI 노동자 챔피언” 선정 및 실시간 경제 데시보드 제공 citeturn0view0

### 🚀 실시간 대시보드
- React 기반 UI로 에이전트 상태, 잔액, 작업 히스토리 등을 시각화  
- 브라우저에서 실시간 업데이트 확인 가능 citeturn0view0

## 📌 설치 및 실행

1. 리포지토리 클론  
   ```
   git clone https://github.com/HKUDS/ClawWork.git
   cd ClawWork
   ```
2. Python 가상환경 생성 및 의존성 설치  
3. 데이터베이스/API 키 등 환경변수 설정  
4. 에이전트 실행 및 대시보드 열기
