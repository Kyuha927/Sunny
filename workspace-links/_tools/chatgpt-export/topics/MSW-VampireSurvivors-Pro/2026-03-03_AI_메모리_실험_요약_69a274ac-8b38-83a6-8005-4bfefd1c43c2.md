## 🚀 핵심 결과 — 요약된 메모리가 *오히려 성능 저하*를 일으킨다

**4가지 메모리 전략 비교 실험 결과:**

| 메모리 전략 | 전체 점수 (5점 만점) |
|-------------|----------------------|
| 경험적 메모리 (Experiential) | **4.55** |
| 합성 메모리 (Synthetic) | **2.65** |
| 하이브리드 (Hybrid) | **4.95** |
| 베이스라인 (Baseline, 메모리 없음) | **3.30** | citeturn0view0

✨ **놀라운 사실!**  
정성 들여 요약된 메모리(합성 메모리)는 *메모리 없음*보다도 성능이 낮았습니다. 즉, “더 많은 지식”이 반드시 더 나은 성능으로 이어지지 않았어요! citeturn0view0

## 🧠 왜 이런 일이 일어났을까? — *과잉확신 효과 (Overconfidence Effect)*

실험에서 연구진은 이렇게 설명합니다:

- **합성 메모리**: 깔끔하고 체계적이지만 요약된 정보는 실제 질문 맥락에서 필요한 뉘앙스를 놓칠 수 있습니다. 이로 인해 에이전트가 *부정확한 지식에 과도하게 신뢰*를 가지게 됩니다. citeturn0view0  
- **베이스라인 에이전트**: 아무 메모리가 없어서 불확실할 때는 스스로 “모르겠다”거나 조건부 답변을 시도해 결과적으로 *보다 신중한 추론*을 합니다. citeturn0view0

👉 이건 인간의 **과잉확신 편향(Dunning–Kruger 효과)**과 유사한 작동으로, 약간의 정보가 “있음에도 불구하고” 오히려 해가 될 수 있다는 점을 보여줍니다. citeturn0view0

## 💡 하이브리드가 최고!

**경험적 메모리 + 합성 메모리**를 결합한 *하이브리드* 접근은 모든 분류에서 압도적 1위를 기록했어요 — 거의 만점에 가까운 4.95점! citeturn0view0

이 조합이 잘 작동하는 이유는 다음과 같아요:

✅ 합성 메모리는 방향과 구조를 준다  
✅ 경험적 메모리는 세부 맥락을 제공한다  
➡️ 두 가지가 결합되면 서로의 약점을 보완하면서 *초선형(superlinear)* 성능 향상을 만든다는 결과입니다. citeturn0view0

## 🧩 실험의 구조

에이전트는 동일한 **20가지 질문**을 받았고, 평가 카테고리는 다음과 같았습니다:  
✔ 정보 검색(IR)  
✔ 비판적 사고(CT)  
✔ 아키텍처 & 설계(AD)  
✔ 맥락 기반 판단(CD) citeturn0view0

결과적으로 **합성 메모리만 가진 경우**는 모든 카테고리에서 낮은 점수를 받았고, **경험적 메모리 기반 질문들**(특히 CD)에서는 원본 로그가 훨씬 강력한 신호를 제공했습니다. citeturn0view0

2. **원본 경험을 보존하라**: 실제 로그/세션/결정 과정은 필수적인 신호를 담고 있습니다. citeturn0view0
