# 1) 스프라이트 임포트(가장 중요)
- **Filter Mode = Point (no filter)**
- **Compression = None**
- **Pixels Per Unit(PPU)**: 프로젝트에서 쓸 하나의 숫자를 정해 **모든 스프라이트에 동일**하게 넣어요.  
  예: 타일이 16×16px이면 PPU=16, 32×32px이면 PPU=32.

# 2) 픽셀 퍼펙트 카메라 설정
- 카메라에 **Pixel Perfect Camera**(URP/내장 공통) 추가
  - **Assets PPU = (위에서 정한 PPU)**  
  - **Reference Resolution**: 실제 게임 뷰포트의 정수배가 되는 해상도를 넣기  
    - 예) 게임창이 960×540이면, 320×180(×3배), 480×270(×2배)처럼 **정수배 관계**가 되도록.
  - **Upscale Render Texture**: **켜면** 화면을 **정수배**로만 확대한 버퍼를 씁니다(가장 안전).
  - Upscale을 끄는 경우엔 **Pixel Snapping**을 **켜서** 서브픽셀 흔들림을 막아요.

# 3) 직교 카메라 크기(월드 단위 ↔ 픽셀 단위 계산)
- 세로 기준 레퍼런스 해상도를 `referenceResolutionY`, PPU를 `PPU`라 할 때:
  ```
  orthographicSize = referenceResolutionY / (PPU * 2)
  ```
  이렇게 두면 “세로 픽셀 수 ↔ 월드 유닛”이 1:1로 맞아, 타일/캐릭터 크기 설계가 쉬워집니다.  
  (예: 320×180, PPU=16 → orthoSize = 180 / (16*2) = 5.625)

# 4) 카메라/오브젝트 스냅 원칙
- **Transform은 정수 단위 스냅**(특히 X/Y).  
- 타일맵/그리드 간격은 스프라이트의 **원본 픽셀 크기/PPU**에 정확히 맞추세요.  
- 애니메이션/트윈으로 소수 이동이 필요하면 **Upscale + Pixel Snapping** 조합으로 아티팩트 최소화.

# 5) URP(Universal Render Pipeline) 튜닝 팁
- **Render Scale = 1.0** (혹은 의도적 슈퍼샘플 시 **정수** 배수만, 예: 2.0)
- **MSAA = Off** (픽셀 아트에선 가장자리 블렌딩이 오히려 흐려짐)
- **Bloom/글로우는 별도 경로**로:
  - 발광 요소를 **Point 필터의 RenderTexture**나 **전용 Renderer Feature 패스**에 렌더 →  
    그 버퍼 크기에서 **간단한 블러**(separable) 처리 → 본 화면에 **Additive** 합성.  
    이렇게 하면 경계 픽셀이 흐트러지지 않으면서도 발광 효과만 부드럽게.
- **Camera → Stop NaNs**: 포스트 효과와 픽셀 퍼펙트 혼용 시 드랍아웃이 보이면 켜두세요.

# 6) 체크리스트(문제 생길 때)
- 스프라이트마다 PPU가 다른가? → **모두 통일**
- 카메라 Asset PPU ≠ 스프라이트 PPU? → **같게**
- Reference Resolution이 현재 뷰포트의 **정수배**인가?
- Upscale을 끄면 **Pixel Snapping**은 켰는가?
- URP Render Scale이 **1.0(또는 정수)**인가?
- MSAA가 켜져 있나? → **끄기**

필요하면 당신 프로젝트 기준으로 PPU/해상도/orthoSize를 바로 계산해 드릴게요. 원하는 타일 픽셀 크기(예: 16px)와 목표 게임창 해상도(예: 960×540)만 알려주세요.
