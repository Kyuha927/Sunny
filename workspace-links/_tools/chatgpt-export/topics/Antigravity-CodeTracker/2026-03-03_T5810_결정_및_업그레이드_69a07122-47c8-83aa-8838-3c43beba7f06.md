✔ NVMe 기반 → SATA보다 체감 빠름  
✔ PCIe 3.0 시스템에서도 읽기/쓰기 충분  
✔ SSD 성능 때문에 개발이 답답하지 않음  
✔ 초기 비용이 작아서 부담 적음

---

# ❗ 유의할 점 (가격 대비 한계)

### 1️⃣ DRAM Cache 여부
저가형 SSD는 **DRAM 캐시가 없거나 미흡**일 수 있음  
→ Random Write 시 성능 저하 구간이 생길 수 있음

### 2️⃣ 컨트롤러 품질 편차
- 제조사/펌웨어가 상급급보다 품질 편차 큼  
→ 장기 안정성에서 불리

### 3️⃣ TBW 스펙이 공식 비공개인 경우
→ 정확한 수명 보증이 없음  
→ 보통 TLC = 중수명 수준으로 추정함

---

## 7) 디스크 여유 자동 감시 (꽉 차면 SSD 망가지는 지름길)

```bash
sudo tee /usr/local/bin/disk-guard.sh >/dev/null <<'SH'
#!/usr/bin/env bash
set -euo pipefail
TH=80
USED=$(df -P / | awk 'NR==2{gsub("%","",$5); print $5}')
if [ "$USED" -ge "$TH" ]; then
  echo "[DISK-GUARD] Root usage is ${USED}% (>=${TH}%) at $(date -Is)" | systemd-cat -t disk-guard -p warning
fi
SH
sudo chmod +x /usr/local/bin/disk-guard.sh

# 매일 09:00 실행
( sudo crontab -l 2>/dev/null; echo "0 9 * * * /usr/local/bin/disk-guard.sh" ) | sudo crontab -
```
