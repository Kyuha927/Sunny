## 왜 필요한가?
SSIM/LPIPS 같은 지각 품질 지표는 자연 이미지에 최적화되어 **16×16~64×64 저해상도, 제한 팔레트**에서는 잘 속습니다. 그래서 *딱딱한* 픽셀 무결성 검사가 먼저 와야 해요.

## 파이프라인 개요 (CI 친화)
1. **바이트 해시 (무리사이즈/무보정)**  
   - 소스 PNG를 바이트 그대로 SHA-256.  
   - 의도치 않은 리샘플·알파 변형·메타데이터 수정까지 적발.
2. **팔레트·색 개수 sanity**  
   - 팔레트 모드(Indexed) 여부, 최대 색상 수(예: ≤32/64) 준수.
3. **연결 성분(CC) 크기 분포**  
   - 너무 작은 점(noise)이나 비정상적으로 큰 덩어리 등장 시 실패.  
   - 히트박스/실루엣 붕괴 조기 감지.
4. **그리드 정합 RLE**  
   - 행·열별 런-길이(run length)가 프레임 간 연속적인지 확인.  
   - 아웃라인이 프레임 전환에서 들쑥날쑥하면 애니메‧션 깨짐.
5. **엣지 보존 비율(EPR)**  
   - Canny(edge) 후, 변환 전후 교집합/합집합 비율로 “윤곽선 보존” 측정.  
   - **미세 블러·서브픽셀 이동**에 민감—가장 신뢰도 높은 지표.
6. **(보조) 지각 해시/유사도**  
   - dHash/pHash로 대략적 동일성 체크(광량 변화, 미세 이동 허용).  
   - SSIM/LPIPS는 **참고용** 경고 레벨로만 사용.

> 정책: **무결성(1~5)**에서 하나라도 실패 → CI 빨간불.  
> **보조(6)**는 노란불(리뷰 필요)로만 처리.

---

## 실패 기준(예시)
- 해시: 기존 승인 해시와 1bit라도 다르면 실패.  
- 팔레트: 색 개수 > 32 또는 팔레트 아님 → 실패.  
- CC: 최소 성분 픽셀수 < 3 또는 최대 성분이 캔버스의 90%↑ → 실패.  
- RLE: 프레임 간 동일 행의 런 개수 변화율 > 25% → 실패.  
- EPR: 0.85 미만 → 실패(윤곽선 손실 의심).  
- dHash/pHash: 거리 > 10 → 경고(리뷰).

---

## 적용 포인트
- **스프라이트시트**: 프레임별 검사 + 프레임 간 RLE/EPR 비교.  
- **업스케일/리샘플 방지**: 해시·EPR이 딱 잡아냄.  
- **도구 체인**: 의도치 않은 색공간/감마 태그 삽입도 해시로 탐지.

## 구현 단서(파이썬 스케치)
```python
from PIL import Image
import hashlib, numpy as np, cv2

def byte_hash(path):
    with open(path,'rb') as f: return hashlib.sha256(f.read()).hexdigest()

def palette_sanity(img: Image.Image, max_colors=32):
    if img.mode not in ('P','LA','RGBA','RGB'): return False
    colors = img.convert('RGBA').getcolors(maxcolors=65536)
    return colors is not None and len(colors) <= max_colors

def epr(before_np, after_np):  # 0~1
    def edges(x):
        return cv2.Canny(cv2.cvtColor(x, cv2.COLOR_RGBA2GRAY), 50, 150)>0
    a, b = edges(before_np), edges(after_np)
    inter = np.logical_and(a,b).sum()
    union = np.logical_or(a,b).sum()
    return inter/union if union else 1.0
```

## 실무 팁
- **기준 아카이브**: 릴리스 승인된 원본을 “락”하고 해시만 비교.  
- **타깃 해상도 고정**: 로더에서 강제 리샘플 금지(오류 시 실패).  
- **프레임 마진 체크**: 투명 여백 폭이 프레임 간 일정한지 검사.  
- **리뷰 축소**: EPR/CC/RLE가 통과하면 SSIM/LPIPS 경고는 무시 가능.
