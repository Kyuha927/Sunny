## 🧠 Perplexity Computer란? — AI의 **완전판 디지털 작업자**

**Perplexity Computer(퍼플렉시티 컴퓨터)**는 단순히 질문에 답하는 AI가 아닙니다.  
Perplexity가 “AI의 다음 진화”라고 정의한 **범용 디지털 작업자**예요.citeturn0view0

---

## 🔥 핵심 개념 — “AI가 프로젝트 전체를 실행한다”

✅ 기존 AI:  
- **채팅 인터페이스** → 질문에 답만 제공  
- **단일 에이전트** → 작업 분절적 처리

✅ **Perplexity Computer:**  
- **전체 워크플로우를 자동 생성·실행**  
- 수시간에서 **수개월짜리 장기 작업**도 처리 가능  
- 인간 동료처럼 **작업 목표를 분석 → 하위 작업 분할 → 실행**citeturn0view0

즉, 단순 질의응답을 넘어 **프로젝트 단위 업무 수행**이 가능합니다.

---

## ⚙️ 어떻게 작동할까?

1. **목표를 설명하면** 컴퓨터가 이해  
2. 이를 주요 작업 + 하위 작업으로 분해  
3. 하위 에이전트들을 생성  
   - **웹 조사**
   - **문서 생성**
   - **데이터 처리**
   - **API 호출**
   - **코딩·배포 등 실제 액션**citeturn0view0

👉 각 에이전트가 동시에 병렬로 돌아가고, 필요하면 다시 문제를 해결하기 위한 새 에이전트를 생성하기도 합니다.  
👉 사용자 개입은 **정말 필요할 때만 요청**되도록 설계되어 있어요.citeturn0view0

## 🤖 기술적 특징

### 🛠️ 진짜 작업 환경에서 실행  
- **파일 시스템**, **브라우저**, **도구 통합** 등 실제 컴퓨팅 환경을 직접 다루며 작동  
- 완전히 **격리된 환경**에서 실행되기 때문에 안전성이 확보돼 있습니다.citeturn0view0

### 🤝 멀티 모델 오케스트레이션  
Perplexity Computer는 단일 AI 모델이 아니라 **여러 프론티어 AI 모델을 조합합니다**:

| 작업 유형 | 사용되는 모델 |
|-----------|----------------|
| 추론/핵심 엔진 | Opus 4.6 |
| 심층 조사 | Gemini |
| 이미지 처리 | Nano Banana |
| 비디오 작업 | Veo 3.1 |
| 긴 텍스트 / 검색 | ChatGPT 5.2 |citeturn0view0

이런 **지능형 멀티 모델 오케스트레이션** 덕분에, 각 모델의 강점을 살려 더욱 유연하고 강력한 멀티스텝 작업이 가능합니다.citeturn0view0

## 📌 중요한 포인트

✅ **완전 자동화된 프로젝트 실행**  
→ 아이디어만 설명하면 여러 단계의 실행까지 AI가 알아서 수행

✅ **실제 환경과 상호작용 가능**  
→ 브라우저, 파일 작업, API 등 현실 도구를 직접 다룸

✅ **최고 성능 모델들을 조합**  
→ 다양한 작업에 최적화된 모델을 자동 배치
