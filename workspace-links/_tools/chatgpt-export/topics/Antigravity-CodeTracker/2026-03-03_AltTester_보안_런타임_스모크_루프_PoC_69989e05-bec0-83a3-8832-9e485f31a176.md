Unity 빌드를 **에디터 밖(CI 환경)**에서 자동으로 켜고, **AltTester Desktop(보안 WSS)**와 **Python 스모크 테스트**로 UI 경로를 검증하는, 바로 복붙해 쓸 수 있는 최소 PoC를 정리했어요. 이 패턴이면 “서버 켜기 → 플레이어 실행 → UI 테스트 → 로그/아티팩트 수집 → 종료”까지 한 번에 돌아갑니다.

## 왜 필요한가?
- 에디터 통과 ≠ 런타임 통과. 실제 빌드(WebGL/Standalone)에서만 터지는 회귀를 초기에 잡습니다.  
- CI에 붙여 두면 메뉴 진입·버튼 탭·기본 HUD 표시 같은 **핵심 UI 가드레일**을 매 커밋마다 체크할 수 있어요.

## 1) AltTester Desktop 보안 배치모드 실행 (WSS)
### Windows (PowerShell)
```powershell
Start-Process -FilePath "C:\Program Files\AltTester\AltTesterDesktop.exe" `
  -ArgumentList '-batchmode -port 13000 -nographics -certificatePath C:/certs/server.pfx -certificatePassword mypass' `
  -NoNewWindow
```

### Linux/macOS (bash)
```bash
./AltTesterDesktop.x86_64 -batchmode -port 13000 -nographics \
  -certificatePath /ci/certs/server.pem -certificatePassword mypass &
```
- `-certificatePath` 지정 시 자동으로 **WSS(보안 웹소켓)** 활성화.  
- Windows는 **PFX**, Linux/macOS는 **PEM** 컨테이너 사용.

---

## 2) 인스트루먼트된 Unity 플레이어 실행
AltTester에 맞게 빌드가 **Secure Mode + host:13000**으로 연결하도록 설정하세요.

### Standalone 예 (Windows)
```powershell
"C:\ci\builds\MyGame\MyGame.exe" -popupHost=127.0.0.1 -popupPort=13000 &
```

### WebGL 팁
- 동일 인증서로 HTTPS 서빙하거나, CI용 헤드리스 브라우저에 `--ignore-certificate-errors` 옵션을 사용.  
- 자체 서명 CA를 러너 신뢰 저장소에 미리 추가하면 연결이 매끈해집니다.

## 3) 초간단 Python 스모크 테스트 (pytest 스타일)
```python
# tests/test_smoke.py
import time
import pytest
from alttester import AltDriver, By

def test_basic_startup():
    alt = AltDriver(host='127.0.0.1', port=13000, app_name='MyGame')
    start_btn = alt.find_object(By.NAME, 'StartButton')
    start_btn.tap()
    alt.wait_for_object(By.PATH, "//MainMenu[@visible='true']", timeout=10)
    assert alt.find_object(By.NAME, 'ProfileIcon') is not None
    alt.stop()
```
- 셀렉터는 `AltId/NAME` → `PATH` 순 추천.  
- `wait_for_object`로 안정적 전환 대기.

## 4) GitHub Actions 예시(Job 하나로 끝)
> 전제: **Self-hosted 러너**(AltTester 설치 + 인증서/빌드 존재)
```yaml
name: alttester-runtime-smoke
on: [push]
jobs:
  smoke:
    runs-on: self-hosted
    steps:
      - uses: actions/checkout@v4
      - name: Setup Python
        uses: actions/setup-python@v4
        with: { python-version: '3.11' }
      - name: Install deps
        run: pip install -r tests/requirements.txt
      - name: Start AltTester (batch, secure)
        run: |
          "C:\Program Files\AltTester\AltTesterDesktop.exe" -batchmode -port 13000 -nographics -certificatePath C:/certs/server.pfx -certificatePassword ${{ secrets.AT_CERT_PASS }} &
        env:
          AT_CERT_PASS: ${{ secrets.AT_CERT_PASS }}
      - name: Start player
        run: |
          start "" "C:\ci\builds\MyGame\MyGame.exe"
      - name: Run smoke tests
        run: pytest tests/test_smoke.py -q --junitxml=report/junit.xml
      - name: Upload logs
        uses: actions/upload-artifact@v4
        with:
          name: alttester-logs
          path: report/
```

## 운영 팁 & 자주 막히는 지점
- **라이선스**: Linux 배치모드는 Pro 라이선스가 필요할 수 있어요(무인 실행 검증 필수).  
- **WebGL/WSS**: 브라우저가 HTTPS를 신뢰해야 AltTester WSS가 붙습니다(신뢰 CA or 러너 사전 신뢰 등록).  
- **러너 선택**: GitHub 호스티드보단 **Self-hosted Windows/Linux**가 가장 쉬움(AltTester가 GUI 네이티브).  
- **예제 레포**: AltTester의 Python Standalone 예제를 템플릿으로 쓰면 시작/정지 스크립트와 리포팅 훅(Allure 등)이 이미 준비돼 편해요.
