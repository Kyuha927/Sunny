# OCR 디버깅 3단계(필수)

1) **실패 PNG 고정 수집**
- 예외 날 때마다 **입력 스크린샷을 그대로 저장**(이미 하고 있음).  
- 규칙: 파일명에 `ts`, `res`, `engine`까지 포함(예: `20260218-224507_Play_520x640_tesseract.png`).

2) **엔진 바꿔 재실행(원인 분리)**
- **Tesseract**와 **EasyOCR** 둘 다 돌려서 비교.
  - 결과 해석:
    - 둘 다 비어 있음 → **입력/전처리 문제**(잘린 영역, 대비, 해상도).
    - 한쪽만 됨 → **엔진 이슈**(사전/언어팩/설정).
- 샘플(Python):
```python
# tesseract
txt1 = ocr_tesseract(img, lang="kor+eng", psm=6)
# easyocr
txt2 = ocr_easyocr(img, langs=["ko","en"])
```

3) **문자 집합 로깅(인코딩 원인 고정)**
- 콘솔/파일 출력 전에 **문자 코드포인트**를 함께 기록.
```python
def safe_log(s: str):
    hexes = " ".join(f"U+{ord(c):04X}" for c in s)
    print("[TEXT]", s)
    print("[UNICODE]", hexes)
```
- 여기서 CP949가 못 찍는 **문자(예: ‘…’, 특수 공백, 이중 바이트 기호)**를 확인하면,
  - A) **출력만 UTF-8로 강제**하거나(Windows 콘솔은 `chcp 65001` + `PYTHONIOENCODING=utf-8`),
  - B) **로그 전용 필터** 적용(문자 치환/제거),
  - C) **파일 로그를 UTF-8**로 저장하고 콘솔에는 축약본만 출력.

# 빠른 체크리스트

- [ ] **좌표/앵커 재확인**: 지금 PNG가 “메뉴”가 아니라 “속성창”이라면 OCR이 비어도 정상입니다. 캡처 영역을 **Play/Start 메뉴 텍스트가 확실히 들어오게** 다시 잡기.
- [ ] **전처리**: 그레이스케일→이진화(Adaptive), 샤프닝, 해상도 ≥ 1.2x 업스케일.
- [ ] **Tesseract 옵션**: `--psm 6` 또는 `--psm 7`(한 줄/짧은 라벨), `kor+eng`, `tessedit_char_blacklist`/`whitelist`로 잡음 억제.
- [ ] **EasyOCR**: `detail=0`, `decoder='greedy'`부터 시작해서 baseline 비교.
- [ ] **출력 경로 분리**: `logger_file(UTF-8)` vs `stdout(요약)`. CP949 환경이면 **콘솔 출력 최소화**.
- [ ] **문자 정규화**: `unicodedata.normalize('NFKC', text)` 후 `translate`로 “비표준 공백/따옴표” 치환.
- [ ] **실패 케이스 스냅샷+메타**: `{engine, lang, psm, thresh, scale}`를 PNG와 함께 저장 → 회귀 재현 용이.

# 권장 패치(윈도우 CP949 방어)

- PowerShell 실행 전 한 번:
```powershell
chcp 65001 > $null
$env:PYTHONIOENCODING="utf-8"
$env:LF_LOG_ENCODING="utf-8"
```
- Python 로거(요지):
```python
import sys, io, logging, os
if os.name == "nt":
    # 표준출력 UTF-8 강제
    sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8", errors="replace")
    sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding="utf-8", errors="replace")

logging.basicConfig(
    handlers=[logging.FileHandler(".logs/run.log", encoding="utf-8"),
              logging.StreamHandler(sys.stdout)],
    level=logging.INFO
)
```

# 입력 vs 엔진 vs 출력, 어디가 문제인지 판정표

- **PNG에서 텍스트가 육안으로 선명** + **한 엔진만 성공** → 엔진 설정/언어팩.
- **PNG에서 텍스트가 작거나 흐림** + **둘 다 실패** → 캡처/전처리/해상도.
- **OCR 텍스트는 나옴** + **로그에서만 예외** → **CP949 출력 문제**(UTF-8 강제·정규화로 해결).
