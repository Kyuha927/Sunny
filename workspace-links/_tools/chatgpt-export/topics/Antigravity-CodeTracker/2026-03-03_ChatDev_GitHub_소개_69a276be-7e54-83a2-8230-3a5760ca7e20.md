## 🚀 ChatDev란?

**ChatDev**는 여러 개의 AI 에이전트가 팀처럼 협력해서 소프트웨어를 만들 수 있도록 설계된 오픈소스 프레임워크예요.  
각 에이전트는 CEO, CTO, 개발자, 디자이너 같은 역할을 맡아 역할 기반으로 개발 생명주기를 자동화합니다.citeturn0search1turn0search12

📌 핵심 특징  
- LLM(대형 언어 모델) 기반 에이전트들이 *대화(chat)*로 협력하며 작업을 수행  
- 소프트웨어 설계 → 코드 작성 → 테스트 → 문서화까지 전체 사이클을 자동화할 수 있음  
- 개별 에이전트 간 대화는 “chat chain”으로 관리돼 협업 품질을 높임  
- 오픈소스로 누구나 코드 수정/확장 가능citeturn0search1turn0search13

💡 기술적 배경: ChatDev는 에이전트들이 자연어 기반으로 협업하고, 각 단계에서 대화 메커니즘을 활용해서 작업을 나누고 수행하도록 설계되어 있어요. 이는 전통적인 소프트웨어 워터폴 모델에 *LLM 기반 다중 에이전트 협업*을 적용하는 방식입니다.citeturn0academia22

## 🆕 ChatDev 2.0 (DevAll)

최근에는 **ChatDev 2.0 — DevAll**이라는 제로코드 멀티 에이전트 플랫폼으로 확장되었고,  
기존 소프트웨어 개발 콘셉트에서 벗어나 *“모든 작업을 위한 에이전트 협업 플랫폼”*으로 진화했어요.citeturn0search8turn0search18

✨ DevAll 주요 개선점  
- **제로 코드(Zero-Code)** 워크플로우 구축 지원  
- **시각적인 워크플로우 편집 UI** 드래그-앤-드롭으로 에이전트 흐름 구성  
- 데이터 시각화, 3D 생성, 연구 자동화 같은 다양한 시나리오 지원  
- Python SDK를 통한 프로그램 제어도 가능citeturn0search8turn0search18

## 📦 설치 및 구성

저장소에는 Python + Node.js 기반 프로젝트 구조가 있으며,  
백엔드와 프런트엔드를 동시에 실행하는 방식으로 동작합니다(로컬 실행 가능).citeturn0view0

예를 들면:  
```bash
# 백엔드 + 프런트엔드 의존성 설치
uv sync
cd frontend && npm install

# 로컬 서버 실행
make dev
```

※ 실제 실행환경은 `README.md`와 공식 가이드를 참고하세요.citeturn0view0
