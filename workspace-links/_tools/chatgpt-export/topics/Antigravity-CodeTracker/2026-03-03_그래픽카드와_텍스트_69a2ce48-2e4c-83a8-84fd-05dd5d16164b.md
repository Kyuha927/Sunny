# 1) “1660에서만” 잔상처럼 보이는 대표 원인 TOP 5 🚨

## ① 주사율이 60Hz로 떨어짐 (가장 흔함)
- 144Hz 모니터인데 60Hz로 잡히면 스크롤 글자가 “잔상/흐림”처럼 보여요.

## ② 브라우저/앱 하드웨어 가속 이슈
- 크롬/엣지에서 특히 발생 가능  
✅ 테스트: **크롬/엣지 → 설정 → 시스템 → “가능한 경우 하드웨어 가속 사용” OFF → 재시작**  
이거로 바로 개선되면 **GPU/드라이버 가속 경로 문제**입니다.

## ③ NVIDIA 드라이버/윈도우 합성(MPO) 버그
- 특정 드라이버 조합에서 스크롤/창 움직임에 잔상·깜빡임·미세한 번짐이 생기는 케이스가 있어요.

## ④ 디스플레이 스케일링/클리어타입 튜닝 꼬임
- 배율(125%/150%) + 특정 렌더링 조합에서 텍스트 가장자리가 스크롤 때 흐려 보이기도 합니다.

## ⑤ 케이블 품질/어댑터/허브
- “같은 모니터”라도 **케이블/허브/변환젠더**가 다르면 증상 갈 수 있습니다.

# 2) 선생님용 “즉시 처방” 순서 🚀 (위에서부터 하면 됩니다)

### A. 주사율 고정
- 고급 디스플레이에서 **최대 Hz로 설정**
- NVIDIA 제어판 → “해상도 변경”에서도 **PC 해상도 항목**으로 잡혀 있는지 확인

### B. 브라우저 가속 OFF 테스트 (30초)
- 크롬/엣지 하드웨어 가속 OFF → 재시작  
✅ 개선되면: 드라이버/합성 문제 쪽으로 확정

### C. NVIDIA 드라이버 클린 설치 (가장 확실 💀)
- **DDU로 삭제 → 최신 드라이버 “클린 설치”**
  - 설치 옵션에 “새로 설치(클린)” 체크

### D. 연결 방식 바꾸기
- HDMI → DP로 변경 (가능하면)
- DP 포트도 다른 포트로 바꿔보기

### E. (마지막 카드) MPO 끄기
- 이건 윈도우 합성쪽 이슈에 먹히는 경우가 많습니다.  
원하면 제가 **복붙용 레지스트리**로 바로 줄게요(원복도 같이).
