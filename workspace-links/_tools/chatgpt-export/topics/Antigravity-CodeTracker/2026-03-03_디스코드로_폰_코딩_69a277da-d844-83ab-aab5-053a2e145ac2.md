🔧 **Remote-OpenCode — 디스코드 기반 원격 코딩 환경**  

이 오픈소스 프로젝트는 Discord 봇을 통해 스마트폰이나 모바일에서도 *언제 어디서든 코딩 환경을 원격으로 손쉽게 구축*할 수 있게 해 줍니다!citeturn0view0

✔ **누구에게 유용할까요?**  
- 출퇴근길이나 이동 중에 코드 작업이 하고 싶은 개발자  
- 환경 설정이 복잡하거나 보안이 꺼려져 서버를 따로 두기 싫은 사람  
- 기존 *OpenCode 사용자*

✔ **주요 기능:**citeturn0view0  
1. **/opencode** – AI 프롬프트 입력 → 스레드 생성 & 실시간 스트리밍 응답 (중간에 중단 가능)  
2. **/work** – 자동으로 Git worktree 생성, 브랜치 작업 → 버튼 한 번으로 PR/삭제  
3. **/code** – 패스스루 모드로 슬래시 명령 없이 일반 메시지로 AI 대화  
4. **/queue** – 여러 작업을 큐에 넣고 순차 실행 + 일시정지/재개 기능  

📦 **설치:**  
```bash
npm install -g remote-opencode
```
