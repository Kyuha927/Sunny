## 작업 2) `src/systems/dialog.lua` Phase 2 계약 리팩터링 (핵심)
### ✅ 단일 구조체 강제
`State.game.dialog` 는 **오직 아래 필드만** 갖는 단일 구조체로 정리한다(필드명/의미 고정):

```lua
State.game.dialog = {
  active = false,
  id = nil,
  lines = nil,
  lineIndex = 1,
  ended = false,

  revealCount = 0,
  revealTimer = 0,
  isRevealed = false,

  choiceIndex = 1,

  inputLockTimer = 0,
}
```

- dialog 관련 추가 상태(예: currentLine, textCache 등)를 **State에 새로 만들지 말고** 필요 시 로컬 계산/함수로 해결.
- Typewriter는 **원문 텍스트(lines의 text)** 를 절대 수정하지 말고, `revealCount/isRevealed`로만 표시 길이를 제어.
- dialog 데이터는 반드시 `data/dialog/*.lua`에서 로드/참조(하드코딩 금지).

### ✅ 공개 API (함수 시그니처 고정)
`src/systems/dialog.lua`에 아래 함수들을 구현/정리한다:

- `start(id)`
- `onLineEnter()`
- `nextLine()`
- `handleChoice()`
- `safeClose(reason)`

**함수 책임**
- `start(id)`:
  - dialog 로드(데이터 파일에서)
  - `State.game.mode = "dialog"` 로 전환
  - `State.game.dialog` 초기화 후 `active=true`
  - 첫 줄 진입을 `onLineEnter()`로 처리
  - 시작 직후 입력 난사 방지 위해 `inputLockTimer` 세팅(짧게, 예: 0.08~0.15s)

- `onLineEnter()`:
  - 현재 line 기준으로 `revealCount=0, revealTimer=0, isRevealed=false`
  - choices가 있으면 `choiceIndex=1`로 클램프
  - `inputLockTimer`를 적절히 재설정(줄 바뀔 때도 연타 방지)

- `nextLine()`:
  - 현재 줄이 마지막이면:
    - `ended=true`
    - `safeClose("end")` 호출
  - 아니면 `lineIndex++` 후 `onLineEnter()`

- `handleChoice()`:
  - 현재 줄 choices 기반으로 선택 확정 로직 처리
  - 선택 결과가 `open_settings` 액션이면:
    - **반드시** `safeClose("scene_switch")` 호출 후 settings 씬으로 전환(아래 “씬 전환 계약” 참고)
  - 그 외:
    - `next`/`goto`/`end` 등 레포에 이미 존재하는 choice 결과 스키마를 존중해서 처리하되,
    - dialog 데이터 구조를 바꾸지 말고, 최소 변경으로 어댑트

- `safeClose(reason)`:
  - dialog UI 잔상/입력 잔재가 남지 않도록 `State.game.dialog`을 “비활성/초기 상태”로 되돌림
  - `State.game.mode`를 reason에 맞춰 정리:
    - `reason == "scene_switch"`: mode는 씬 전환 측에서 최종 결정(다만 dialog active는 반드시 false)
    - 그 외(예: `"end"`, `"user_cancel"` 등): `State.game.mode="combat"` 로 복귀
  - settings는 오직 `State.settings`에만 저장/유지되도록 보장

### ✅ 입력 계약 (confirm/up/down + inputLockTimer)
- 입력은 **반드시** `src/core/input.lua`에서 읽어온 결과를 사용 (직접 love.keyboard 금지)
- `inputLockTimer > 0` 이면 **모든 입력 무시**
- confirm 키: `Enter` 또는 `Space`

**confirm 처리 순서(절대 고정)**
1) typing 중(`isRevealed == false`) confirm → `revealAll` (즉시 완전표시)
2) revealed + choices 있음 confirm → `confirmChoice` (현재 `choiceIndex` 확정 → `handleChoice()`)
3) revealed + choices 없음 confirm → `nextLine()`

**up/down**
- `choices && revealed` 일 때만 동작
- 그 외(typing 중 포함)면 무시
- `choiceIndex`는 반드시 `1..#choices`로 클램프

## 작업 3) GameScene mode 분기 보장 (combat 차단)
- `State.game.mode == "dialog"` 동안:
  - combat 관련 update가 **절대** 돌지 않게 분기 고정
  - combat 입력 처리도 **절대** 돌지 않게 분기 고정
- `pause`에서도 dialog/combat 일관성이 유지되도록:
  - pause 진입/복귀 시 mode 전환이 오직 `State.game.mode`로만 일어나게 정리
  - dialog 활성 상태에서 pause 들어갔다가 복귀하면 dialog 그대로 유지(또는 스펙에 맞는 기존 정책 유지). 단, QA 9번 통과가 최우선.

local function processSpaceHold(dialog, line, limit, dt)
  local runtime = runtimeState(dialog)
  if not Input.down("space") then
    runtime.holdRepeatTimer = 0
    return nil
  end
  if Input.pressed("space") then
    if not dialog.isRevealed then
      setRevealAll(dialog, limit)
      runtime.autoTimer = 0
      runtime.holdRepeatTimer = CONFIG.spaceHoldRepeatDelay
      return nil
    end
    runtime.holdRepeatTimer = CONFIG.spaceHoldRepeatDelay
    return resolveConfirm(dialog, line, limit)
  end
  if not dialog.isRevealed then
    setRevealAll(dialog, limit)
    runtime.autoTimer = 0
    runtime.holdRepeatTimer = CONFIG.spaceHoldRepeatDelay
    return nil
  end
  runtime.holdRepeatTimer = math.max(0, runtime.holdRepeatTimer - dt)
  if runtime.holdRepeatTimer <= 0 then
    runtime.holdRepeatTimer = CONFIG.spaceHoldRepeatDelay
    return resolveConfirm(dialog, line, limit)
  end
  return nil
end
