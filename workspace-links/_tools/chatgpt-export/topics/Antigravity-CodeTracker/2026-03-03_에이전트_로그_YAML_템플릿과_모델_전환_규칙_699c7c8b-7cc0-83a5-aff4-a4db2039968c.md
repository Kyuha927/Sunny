### 1) 에이전트 실행 로그용 프런트매터(복붙용)

```yaml
---
id: ag_log_{{timestamp}}
agent: antigravity
skill: file_writer
model: gemini-3.1-pro
model_version: stable
timestamp: 2026-02-24T12:34:56Z
artifact_type: note|screenshot|trace
prompt_summary: '...'
prompt_hash: sha256(...)
inputs: [path/to/input.md]
outputs: [path/to/output.md]
actions: ['search','write','open_url']
provenance: {mcp_session: xxxxx, tool_calls: [...] }
confidence: 0.87
status: success
tags: [agent, autogen]
---
```

- `id`: 실행 시각 붙여 유니크 값으로.
- `artifact_type`: 결과물 유형(문서/스크린샷/트레이스).
- `prompt_summary`, `prompt_hash`: 요약/무결성 추적.
- `provenance`: 세션/툴 호출 이력(재현성 확보).

### 2) 모델 라우팅 빠른 규칙(실무 축약)

- **UI/DOM·스크린샷·멀티모달 추론 → Gemini 3.1 Pro**  
  (화면 구조 이해, 이미지+텍스트 혼합, 툴 연동 시 안정적)
- **장문 문서 합성·프로젝트 전역 추론·에이전트 오케스트레이션 → Claude Sonnet 계열(권장: Sonnet 4.6)**  
  (긴 컨텍스트, 코드/문서 읽기, 설명력 우수)
- **민감/사내 데이터 처리 → 로컬 LLM 또는 게이트된 Sonnet 인스턴스**  
  (지연/비용/보안 트레이드오프를 설정에서 튜닝)

> 팀 설정 예시:  
> - default: Sonnet 4.6 (길게 읽고 쓰는 작업)  
> - multimodal: Gemini 3.1 Pro  
> - private: Local LLM (온프렘)

### 3) 저장소 템플릿(README에 붙이기 좋은 스니펫)

```md
## Agent Run Log Convention
- File name: `logs/ag_log_YYYYMMDD_HHMMSS.md`
- Frontmatter: 위 YAML 사용(필수 키: id, model, timestamp, artifact_type, status)
- Body sections:
  1. **Goal**: 한 줄 목표
  2. **Context**: 입력/제약 요약
  3. **Plan**: 단계별 실행 계획
  4. **Trace**: 액션 로그(actions와 매핑)
  5. **Outputs**: 산출물 경로/샘플
  6. **Postmortem**: 실패/재시도 포인트
```

### 4) 워크플로 체크리스트(짧고 강력)

- [ ] **프롬프트 요약/해시** 기록  
- [ ] **입출력 경로** 절대/상대 표준화  
- [ ] **툴 호출 로그**(actions)와 결과 매핑  
- [ ] **모델 라우팅 근거** 남기기(Gemini/Claude/Local)  
- [ ] 실패 시 **Postmortem**(원인, 재현 단계, 픽스안)
