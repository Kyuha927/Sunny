확인해보니 **Obsidian 공식 문서의 “Headless Sync”** 페이지는 다음과 같은 기능과 사용법을 정리해줘요 👇 citeturn0view0  

🎉 **Obsidian Sync 헤드리스(Headless)란?**  
- **GUI 없이(데스크톱 앱 없이)** 명령줄에서 Obsidian Sync를 실행할 수 있는 **헤드리스 클라이언트**예요. citeturn0view0  
- CI 파이프라인, 자동화 에이전트, 서버 환경 등에서 **동기화를 자동화**하고 싶을 때 유용합니다. citeturn0view0  
- Sync 플랜(구독)이 **적용된 계정에서만 사용**할 수 있어요. citeturn0view0  

💡 **핵심 특징**  
- 공식 데스크톱 앱과 **같은 암호화/보안** 방식을 써요. citeturn0view0  
- 명령줄에서 원격 Vault 조회, 설정, 동기화 등을 가능하게 해줘요. citeturn0view0  

📦 **설치 & 실행 예시(Command Line)** citeturn0view0  

```bash
# 설치
npm install -g obsidian-headless

# 로그인
ob login

# 원격 Vault 목록 확인
ob sync-list-remote

# 로컬 Vault에 Sync 설정
cd ~/vaults/my-vault
ob sync-setup --vault "My Vault"

# 한 번만 동기화
ob sync

# 계속 감시하면서 동기화
ob sync --continuous
```

📌 **중요 주의사항**  
- 같은 기기에서 **데스크톱 Sync와 Headless Sync를 동시에 쓰면 충돌**이 날 수 있으니, 한 가지 방식만 쓰세요. citeturn0view0
