# 목소리 → 웹훅 → 집안(LAN) → WOL → 로컬 에이전트

**개념 흐름**
1) 휴대폰 음성 트리거(Bixby/Android Assistant+Tasker 또는 Siri Shortcuts)  
2) 안전한 **공개 웹훅** 호출(POST)  
3) **암호화 터널**로 집 라우터 안쪽의 미니 웹서버까지 전달  
   - Tailscale Funnel 또는 Cloudflare Tunnel  
4) 웹서버가 **Wake‑on‑LAN(WOL) 매직 패킷** 전송 → PC 켜짐  
5) 부팅 후 로컬 **에이전트(HTTP/gRPC)**가 작업 큐 받아 처리(콜드스타트 감안)

---

## 1) 휴대폰: 음성 트리거로 웹훅 호출
- **iOS**: “단축어”에서 *웹 요청* 액션으로 `POST https://your-webhook.example/poke` + 헤더(`Authorization: Bearer <short-token>`)  
- **Android**: Tasker/Shortcuts/Assistant 루틴에서 **HTTP Request** 액션 동일 구성  
- 전달 바디 예시:
```json
{
  "action": "wake_and_run",
  "job": "open_local_ai_and_prompt",
  "args": {"prompt":"회의 요약 시작"}
}
```

---

## 2) 터널: 외부→내부 안전 연결
- **Tailscale Funnel**: 퍼블릭 URL을 바로 로컬 포트로 터널링(엔드 투 엔드 암호화, ACL 관리 쉬움)  
- **Cloudflare Tunnel**: 클라우드 에지로 공개하고 로컬로 역방향 연결(Access 정책으로 보호)

> 포인트: **웹훅 엔드포인트는 반드시 인증**(짧게 사는 토큰)과 **IP/레이트 제한**을 걸기.

---

## 3) 로컬 웹훅 수신기(예: Python FastAPI)
- 역할: 토큰 검증 → **idempotent**한 작업 아이디 발급 → **WOL 전송** → **작업 큐에 적재** → 즉시 202/Accepted 응답
```python
from fastapi import FastAPI, Header, HTTPException
import hashlib, time, queue, threading, wakeonlan

app = FastAPI()
jobs = queue.Queue()

def wol(mac, bcast="192.168.0.255"):
    wakeonlan.send_magic_packet(mac, ip_address=bcast)

@app.post("/poke")
def poke(x_auth: str = Header(None), payload: dict = {}):
    if x_auth != "Bearer SHORT_LIVED_TOKEN":
        raise HTTPException(401, "unauthorized")
    jid = hashlib.sha256(str(time.time()).encode()).hexdigest()[:12]
    # WOL 먼저
    wol("AA:BB:CC:DD:EE:FF")
    # 큐에 작업 넣기(멱등 키 포함)
    jobs.put({"id": jid, "payload": payload})
    return {"status":"accepted","job_id":jid}
```

## 4) WOL 필수 설정(윈도우 기준)
- **BIOS/UEFI**: Wake on LAN/PCIe Device Power On **Enabled**  
- **Windows** 장치 관리자 → NIC 속성  
  - 전원 관리: “이 장치가 컴퓨터를 깨울 수 있음” 체크  
  - 고급: “Wake on Magic Packet” **Enabled**  
- **S5(완전 종료) 지원**은 메인보드/펌웨어마다 다름(안 되면 **절전(S3/S4)** 모드 활용)  
- **스위치/공유기**: 같은 브로드캐스트 도메인에 있어야 함(또는 라우터의 WOL 프록시/ARP 바인딩 사용)

---

## 5) 로컬 에이전트(HTTP/gRPC) 설계 포인트
- **큐 기반(stateful) 처리**: 부팅 직후 콜드스타트 동안은 *수신만 하고 보류*  
- **짧게 사는 토큰**(예: 60초) + **멱등 키**(동일 작업 중복 실행 방지)  
- **지수 백오프 재시도**: 1s→2s→4s… 최대 N회  
- **준비 신호(health/ready)**: 앱 초기화 끝나면 `/ready=ok` → 그때부터 본 실행  
- **예시 워크**: “로컬 LLM 서버 켜기 → 세션 열기 → 프롬프트 전달 → n분 뒤 자동 종료/슬립”

---

## 6) 자동 종료/유휴 정책
- 에이전트가 **마지막 요청 시각**을 기록하고, 예: **8분 유휴** 시 `shutdown /s /t 0` 또는 슬립 진입  
- 긴 작업은 큐에 **타임아웃**을 붙여 좀비 방지

## 8) 보안 최소 수칙
- **토큰 TTL** 짧게, 사용 시마다 **회전**  
- **허용 IP/국가 제한**(터널/에지에서)  
- **레이트리밋**(예: 5 req/min)  
- **감사 로그**(요청 시각/UA/job_id)  
- **비상 스위치**: 원격에서 공개 엔드포인트 즉시 차단 가능해야 함
