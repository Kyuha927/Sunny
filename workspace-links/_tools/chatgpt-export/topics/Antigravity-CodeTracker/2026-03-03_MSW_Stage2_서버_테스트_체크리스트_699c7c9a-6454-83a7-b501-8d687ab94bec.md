# Stage2 서버 컴팩트 테스트 체크리스트

## A. 소유자/유저ID(Owner–UserID) 경계
- **자기 소유 엔터티만 조작 가능해야 한다**: 서로 다른 `userId`로 동시에 업그레이드/명령 전송 시 교차 적용(남의 유닛이 반응), 권한 오류 로그 누락, 고아(Owner 없음) 엔터티가 생기면 실패.  
- **세션 재연결 후 소유권 재확인**: 재접속 시 이전 소유 엔터티가 이중 소유(양쪽에서 조작) 되거나 미소유 상태로 남으면 실패.  
- **파티/스쿼드 소유 공유 규칙 검증**: 파티 리더만 가능한 명령이 모든 파티원에게 허용되거나, 반대로 정당한 공유가 막히면 실패.  
- **치트/리플레이 공격 방어**: 클라가 임의 `userId`로 RPC 위조 시 서버가 묵살하지 못하거나 사일런트 성공하면 실패.  

## B. 10Hz 타이머 스트레스(서버 틱/주기성)
- **10Hz 고정 루프에서 스폰/공격/XP 동시 처리**: 10분 이상 구동 시 틱 드리프트(누적 지연), 타임스탬프 역행, 타이머가 배수로만 발화(스큐 현상)하면 실패.  
- **부하 상향(유닛 N배) 시 안정성**: CPU 스파이크 후 틱 스킵이 장기화되거나, 보상 연산으로 한 틱에 과도한 이벤트 폭주(폭발적 스폰)면 실패.  
- **모노토닉 시간 의존성**: 시스템 시간 변경(앞/뒤로) 시 쿨다운/버프가 비정상 단축·연장되면 실패.  
- **타이머 해제/재등록 누수**: 웨이브 종료 후에도 타이머 핸들 수가 줄지 않거나, 중복 발화(더블 틱) 발생 시 실패.  

## C. 스폰/XP/레벨업(Spawn–XP–LevelUp) 흐름
- **스폰 캡·주기 준수**: `spawnCap` 초과 생성, `spawnPeriod` 무시(폭주), 디스폰 후 슬롯 회수 지연이면 실패.  
- **공격/피해–킬–XP 적립 선후관계**: 동일 타깃에 중복 처치로 XP 2중 적립되거나, ‘어시스트’ 규칙 누락/중복 지급이면 실패.  
- **레벨업 롤(3선택) 표시/고정성**: 클라 재요청 때마다 선택지가 바뀌거나(비결정성), 서버와 UI의 선택 인덱스 불일치면 실패.  
- **업그레이드 적용 범위**: 개인 버프가 글로벌에 퍼지거나(전장 전체 피해 증가), 수치가 세션 간 누적(리셋 실패)되면 실패.  
- **세이브/리스토어 일관성**: 재접속 후 `xp/lv/xpToNext` 역행·초과, 보상 중복 수령(롤백 악용) 시 실패.  

## D. 상태 비동기화(Desync) 자동 백필(Backfill)
- **주기적 스냅샷 → 클라 재동기**: 스냅샷 수신 후 위치/HP/버프가 점프하거나(테레포트 느낌), 보간 없이 튀면 실패.  
- **결정적 재계산(리플레이/서버 권위)**: 동일 입력으로도 재계산 결과가 다르면(난수 시드 불일치) 실패.  
- **패킷 손실/지연 내성**: N초(예: 3s) 네트워크 정지 후 재개 시 상태가 회복되지 않거나, 누락 이벤트가 영구 소실되면 실패.  
- **충돌 해결 규칙 우선순위**: 동시 타격/루팅에서 서버판정과 클라표시가 불일치(승자 바뀜)하면 실패.  
- **속성 합성의 교환 법칙/결합 법칙**: 버프 적용 순서에 따라 최종 수치가 달라지면(비결합성) 실패.  

## E. 부하·회귀·보안 빠른 점검
- **핫조인/핫리브**: 새 플레이어 합류/이탈 시 남은 엔터티의 타겟팅·어그로가 깨지면 실패.  
- **메모리/핸들 누수**: 웨이브 반복 100회 후 메모리 상승 추세 지속, GC 후에도 회복 불가면 실패.  
- **RPC 스로틀/쿨다운**: 클라가 초당 과다 입력 시 서버 CPU 급등, 큐 적체로 틱 밀림이면 실패.  
- **로그·메트릭 가시성**: 실패 상황에서 원인 추적 키(소유자ID, 엔터티ID, 틱번호, 시드)가 로그에 없으면 실패.

## 실행 팁(짧게)
- **시드 고정**: 재현 가능성 확보(난수 `seed` 고정).  
- **부하 프리셋**: `N=1x, 5x, 10x` 세트로 틱 지연/스폰율 비교.  
- **네트워크 시뮬**: 지연/패킷 드롭/재정렬 삽입으로 백필 경로 자동 검증.  
- **알람 기준선**: 틱 지연 p99, 스폰 위반 횟수, XP 이중 적립 카운터, 스냅샷 재동기 실패율을 대시보드화.

필요하면 위 항목들을 **자동 테스트 스크립트 템플릿**(예: 시드·부하·네트워크 조건 매개변수화)으로 바로 뽑아드릴게요.
