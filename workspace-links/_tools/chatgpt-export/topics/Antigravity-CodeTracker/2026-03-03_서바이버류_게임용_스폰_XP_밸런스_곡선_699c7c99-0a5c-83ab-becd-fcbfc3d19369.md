### 1) 레벨업 경험치: 지수형 목표값
- **공식**: `XP(L) = base * growth^(L-1)`
- **튜닝 범위**: `base = 50–200`, `growth = 1.10–1.35`
- **특징**: 초반은 빠르게 레벨업, 후반은 점진 감속 느낌(체감 난이도 안정).
- **빠른 적용 예 (Lua/Python 유사)**:
```python
def xp_to_next(level, base=100, growth=1.2):
    return int(base * (growth ** (level-1)))
```

### 2) 스폰 강도 램프: 시그모이드(완만-집중-완만)
- **정규화 시간** `t ∈ [0, 1]`
- **공식(알제브라 시그모이드)**:  
  `spawnFrac(t) = t^k / (σ^k + t^k)`
- **튜닝**: `k = 2–6`(경사), `σ = 0.35–0.6`(중심)  
  → 러닝 중반부에 **난이도 피크**를 몰아주고, 시작·종료는 부드럽게.
- **적용 팁**: `현재진행시간 / 러닝길이 = t`로 계산 후, `기본 스폰율 * spawnFrac(t)`를 곱하기.

### 3) 웨이브 빌더: 예산 기반 구성
- **선형 예산**: `budget_w = B0 + w * Δ`  
  **지수 예산**: `budget_w = B0 * growth^w`
- **튜닝**: `B0 = 10–30`, `Δ = 3–8` 또는 `growth = 1.05–1.15`
- **절차**:
  1) 웨이브별 **예산** 계산  
  2) 적 풀에서 **코스트** 기준으로 샘플링(예산 소진 시 종료)  
  3) 실시간 **강도 피드백(플레이어 체력/히트율/시간 압박)**으로 예산에 가중치 ±(AI 디렉터 느낌)
- **샘플 의사코드**:
```python
def build_wave(wave, catalog, B0=20, growth=1.08, intensity=1.0):
    budget = int(B0 * (growth ** wave) * intensity)
    picks = []
    while budget > 0:
        enemy = sample_by_weight(catalog)   # {id, cost, weight}
        if enemy.cost <= budget:
            picks.append(enemy.id)
            budget -= enemy.cost
        else:
            break
    return picks
```

## 빠른 통합 가이드 (MSW Stage2에 드롭인)
- **서버 루프에 3개만 연결**:
  1) **XP**: 적 처치 시 `xp += reward`; `xp >= xp_to_next(lv)`면 `lv += 1` 및 업그레이드 3선택 표시.
  2) **스폰**: 런타임 `t`로 `spawnFrac(t)` 계산 → `baseSpawnRate * spawnFrac(t)`로 스폰 주기/수량 조정.
  3) **웨이브**: 웨이브 시작 시 예산 계산 → 코스트 샘플링으로 적 리스트 생성 → 전투 중 **intensity**로 가중치 실시간 조절.

### 실전 튜닝 체크리스트
- 초반 2~3분 **몰입 부스팅**: `base` 낮게, `growth` 1.2±, 스폰 `σ≈0.45, k≈3` 권장  
- 중반 피크 확보: 웨이브 예산은 지수형 `growth 1.08–1.12`부터 시작
