## “지금 당장” 효과 큰 베스트 팁 10개
문서 전체 70+ 팁 중, 체감이 큰 것만 뽑아 요약하면:

1. **큰 문제를 ‘단계별 체크 가능한 작업’으로 분해**
   - “로그인 페이지 만들어줘” 대신: 스키마 → 마이그레이션 → UI → API → 토큰 저장/리다이렉트 → 실패 시나리오 테스트처럼 쪼개기.

2. **Plan 모드(계획) vs YOLO 모드(실행) 구분**
   - 복잡/대규모 리팩토링은 **Plan 모드**로 “승인 전까지 수정 금지” 흐름을 타고,
   - 반복/단순/격리 환경 작업은 YOLO도 가능(단, 위험).

3. **컨텍스트는 ‘우유’처럼 신선하게**
   - 한 세션에서 여러 목표 섞지 말고, 탭/세션 분리.
   - 길어지면 HANDOFF.md로 넘기고 /clear로 리셋.

4. **/context로 “무엇이 토큰을 먹는지” X-ray처럼 확인**
   - 시스템 프롬프트, MCP, 메모리 파일(CLAUDE.md), 대화기록이 얼마나 차지하는지 보고 정리.

5. **Tier 1 슬래시 명령어를 습관화**
   - /usage, /clear, /stats, /context 같은 “생존 필수”부터 루틴으로.

6. **`!` Prefix로 셸 명령 즉시 실행**
   - “git status 실행해줘” 대신 `!git status`로 바로 결과 주입(속도/토큰 절약).

7. **CLAUDE.md를 ‘짧고 강하게’**
   - 프로젝트 규칙/스택/금지사항을 간결히.
   - /init으로 초안 생성 후, 필요할 때만 업데이트.

8. **세션 관리(/rename, --continue, --resume, /export)**
   - 중요한 작업은 세션 이름 붙이고, /export로 지식 자산화.

9. **안전장치: Sandbox / 컨테이너로 권한과 위험 격리**
   - 반복적으로 안전한 명령은 sandbox 경계로 자동 승인,
   - YOLO는 “컨테이너 안에서만”을 기본 원칙으로.

10. **Headless 모드(-p)로 CI/CD에 통합**
   - 파이프라인에서 diff를 넣고 리뷰를 뽑는 식의 자동화로 확장.

## 오늘 적용 가능한 “1시간 셋업 체크리스트”
원하시면 이대로 복붙해서 적용할 수 있게 구성했습니다.

### 1) 기본 생산성 세팅
- 별칭: `c, cc, cr, ch` 같은 실행 단축(문서 예시처럼)
- **상태 라인(status line)**: 토큰/브랜치/모델/MCP 상태가 보이게 구성

### 2) 프로젝트마다 기본 문서화
- 새 프로젝트 시작 시: `/init`으로 **CLAUDE.md 자동 생성**
- 팀이면: `.claude/` 폴더로 팀 규칙(permissions/hooks 등) 공유

### 3) 컨텍스트 관리 루틴
- 작업 시작: `/usage` 한 번
- 성능 저하 느낌: `/context` 확인 → 불필요 MCP 끄기/세션 분리
- 길어짐: HANDOFF.md 생성 → `/clear` → HANDOFF.md 로드

### 4) 안전한 자동화(권장 순서)
- 1단계: `!` prefix로 반복 명령을 빠르게
- 2단계: `/sandbox`로 “안전 명령 자동 승인” 경계 만들기
- 3단계: Hooks로 위험명령 차단(가드레일)
- 4단계: 컨테이너에서 YOLO/대형 작업
