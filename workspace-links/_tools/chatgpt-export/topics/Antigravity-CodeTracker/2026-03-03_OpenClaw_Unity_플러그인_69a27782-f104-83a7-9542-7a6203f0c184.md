## 🔧 OpenClaw Unity Plugin — 개요

이 저장소는 **Unity 에디터를 OpenClaw AI와 연결해주는 플러그인**이야.  
즉, **OpenClaw AI 에이전트를 Unity 에디터에 직접 붙여서** 게임 씬을 조회하거나 오브젝트를 조작하고, 디버그하거나 코드를 실행하는 등 **AI가 Unity 자체를 제어할 수 있게** 만들어주는 도구야. citeturn0view0

---

## 💡 핵심 기능 요약

### 🧠 AI 기반 Unity 제어

OpenClaw AI로 다음 같은 작업을 할 수 있어! citeturn0view0

- **씬 확인 및 탐색** — 씬의 전체 계층 구조를 읽어들이고 AI에게 설명받기  
- **게임 오브젝트 생성/삭제/수정** — 이름, 태그, 컴포넌트 속성 등 조작  
- **콘솔 로그 조회/클리어** — Unity 로그를 AI로 질의/분석  
- **스크립트 파일 검색/실행** — C# 파일 읽기/실행 명령 전달  
- **에디터 조작** — 재컴파일, 도메인 리로드, 윈도우 포커스 등  
- **입력 시뮬레이션** — 마우스·키보드 입력 흉내를 통한 자동화 테스트 citeturn0view0

---

## 🔄 연결 아키텍처

이 플러그인은 두 가지 연결 모드를 제공해! citeturn0view0

1. **OpenClaw Gateway**  
   - 원격 또는 로컬에서 HTTP 기반 통신으로 AI와 Unity가 연결  
   - 텔레그램, 디스코드 등 외부 채팅 앱과도 통합 가능

2. **MCP Direct (Local)**  
   - 로컬에서 Claude Code 같은 AI 클라이언트 ↔ Unity 직접 통신  
   - 지연(lag)이 더 적고 개발 중 빠른 테스트 가능
