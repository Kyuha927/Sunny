## 📊 Remote Control vs. 웹의 Claude Code

| 기능 | Remote Control | 웹 Claude Code |
|------|------------------|-----------------|
| 실행 위치 | 로컬 머신 | Anthropic 클라우드 |
| 로컬 파일/도구 접근 | ✅ | ❌ |
| 다른 기기 접속 | ✅ | ❌ |
| 클라우드 실행 | ❌ | ✅ |
| 적합 시나리오 | 로컬 개발 계속 | 클라우드 기반 작업 |

👉 로컬에서 시작한 작업을 “계속”하고 싶을 때는 **Remote Control**, 클라우드 환경에서 새 작업 시작할 때는 **웹 Claude Code**를 선택하면 됩니다. citeturn0view0
