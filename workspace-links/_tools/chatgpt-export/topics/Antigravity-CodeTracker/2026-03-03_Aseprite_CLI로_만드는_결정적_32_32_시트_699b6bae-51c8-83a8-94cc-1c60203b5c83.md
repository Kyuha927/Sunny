### 왜 이렇게 하나요?
- 애니메이션(예: `walk`, `idle`)을 **태그(tag)** 로 관리하면, 빌드할 때마다 **동일한 파일명·프레임 순서**로 PNG 스프라이트시트와 JSON 메타를 얻을 수 있어요.
- 버전 고정(핀) + 고정된 CLI 플래그 → 팀/CI/머신이 달라도 아웃풋이 동일.

### 준비
1) **Aseprite 버전 핀 고정**  
- 권장: **v1.3.16** (프로젝트/CI에서 같은 버전 사용)  
- 로컬과 CI(예: GitHub Actions) 모두 같은 실행 파일을 쓰세요.

2) **.aseprite 파일에서 태그 정의**  
- 타임라인에서 `walk`, `run`, `attack` 같은 태그를 만들어 두세요.

### 핵심 한 줄 (예시)
아래 커맨드는 **각 태그를 행(row) 기준으로 정렬한 스프라이트시트**와 **json-array 포맷 메타데이터**를 만듭니다. 파일명/태그명이 포함된 **결정론적 파일명**을 강제합니다.

```bash
aseprite -b \
  --list-tags \
  --sheet myatlas.png \
  --data myatlas.json \
  --format json-array \
  --sheet-type rows \
  --filename-format "{title}|{tag}|{frame}" \
  --tagname-format "{title}|{tag}" \
  input.aseprite
```

- `--list-tags` : .aseprite 안의 태그들을 기준으로 내보냄  
- `--sheet-type rows` : 태그마다 **한 줄(row)** 로 깔끔히 정렬  
- `--format json-array` : 다수 엔진/툴체인 친화적인 JSON 배열  
- `--filename-format` / `--tagname-format` : **항상 같은 패턴** 보장  
  - 예: `MyChar|walk|0003.png` 같은 규칙적 이름

> 결과: `myatlas.png` + `myatlas.json` (언제 실행해도 같은 구조/순서)

### 플랫폼별 실행 팁


### CI에 넣는 최소 스텝
1) Aseprite **버전 고정 바이너리** 캐시/체크아웃  
2) 위 **단일 CLI 명령** 실행  
3) 산출물 `myatlas.png`, `myatlas.json` 아티팩트/커밋

```yaml
# 예: GitHub Actions 스케치
- name: Export sprite atlas
  run: |
    ./aseprite -b \
      --list-tags --sheet build/myatlas.png \
      --data build/myatlas.json --format json-array \
      --sheet-type rows \
      --filename-format "{title}|{tag}|{frame}" \
      --tagname-format "{title}|{tag}" assets/input.aseprite
```

### 흔한 문제 & 빠른 해결
- **프레임 순서가 뒤죽박죽** → 태그 범위를 타임라인에서 정확히 지정하고, 위 플래그 그대로 사용.  
- **파일명이 매번 달라짐** → `--filename-format` 을 절대 바꾸지 말고, `{frame}`에 0패딩이 자동 적용되도록 두세요.  
- **시트 레이아웃이 매번 달라짐** → `--sheet-type rows` 로 고정(열/자동 배치 대신).  
- **여러 입력 파일** → `input1.aseprite input2.aseprite ...` 식으로 나열하거나, 에셋별로 반복 실행.
