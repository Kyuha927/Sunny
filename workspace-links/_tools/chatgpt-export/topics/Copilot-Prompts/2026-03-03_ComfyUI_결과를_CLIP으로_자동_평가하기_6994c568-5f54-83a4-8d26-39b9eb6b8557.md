# ComfyUI 배치 생성 → CLIP 점수화 → 상위 N장 선별

## 개요
- **ComfyUI**: 이미지 생성 워크플로우를 JSON(API 포맷)으로 저장/재현 가능.
- **CLIP 스코어링**: 오픈소스 `open-clip-torch`로 텍스트–이미지 유사도 점수 계산.
- **결과**: 배치로 생성된 이미지 중 **프롬프트와 가장 잘 맞는 상위 N장만** `out/selected/`에 복사.

---

## 1) ComfyUI 서버 실행(헤드리스)
```bash
cd $COMFYUI
pip install -r requirements.txt
python main.py &> comfy.log &
# 기본 포트: 8188 (/prompt, /history 제공)
```

## 2) 워크플로우 저장 + 큐잉
ComfyUI 프론트엔드에서 **“Save (API Format)”**로 `workflow_api.json` 저장 후:
```bash
curl -X POST http://127.0.0.1:8188/prompt \
  -H 'Content-Type: application/json' \
  -d @workflow_api.json
# 응답: {"prompt_id":"..."}
```

## 3) 완료 대기 & 아웃풋 수집
```bash
curl http://127.0.0.1:8188/history/<prompt_id> | jq '.outputs'
# 서버가 돌려주는 /view 리다이렉트 URL 또는 파일 경로로 다운로드
mkdir -p out/comfy/batches
# 예: URL 목록이 urls.txt라면
wget -i urls.txt -P out/comfy/batches
```

## 4) CLIP 설치 & 선택 스크립트
```bash
python -m pip install open-clip-torch pillow torch torchvision tqdm
```

`tools/clip_select.py`:
```python
import open_clip,torch,os,shutil
from PIL import Image
from pathlib import Path
from tqdm import tqdm

model_name='ViT-L-14'
model,_,preprocess = open_clip.create_model_and_transforms(
    model_name, pretrained='laion2b_s32b_b79k'
)
tokenizer = open_clip.get_tokenizer(model_name)
device = 'cuda' if torch.cuda.is_available() else 'cpu'
model.to(device).eval()

prompt='hero idle front sprite'  # ← 점수화 기준 텍스트(바꿔 쓰세요)
text = tokenizer([prompt]).to(device)
with torch.no_grad():
  tfeat = model.encode_text(text)
  tfeat = tfeat / tfeat.norm(dim=-1,keepdim=True)

inp = Path('out/comfy/batches')
outdir = Path('out/selected')
outdir.mkdir(parents=True,exist_ok=True)
scores=[]
for p in tqdm(list(inp.glob('*.png'))):
  img = preprocess(Image.open(p)).unsqueeze(0).to(device)
  with torch.no_grad():
    if img.shape[1]==1: img = img.repeat(1,3,1,1)
    if hasattr(model,'encode_image'):
      ifeat = model.encode_image(img)
    else:
      raise SystemExit('model.encode_image missing')
    ifeat = ifeat/ ifeat.norm(dim=-1,keepdim=True)
    s = float((100.0 * (ifeat @ tfeat.T)).cpu().numpy()[0,0])
  scores.append((s,p))

scores=sorted(scores,reverse=True,key=lambda x:x[0])
# 상위 20장 복사(원하면 수 바꾸세요)
for _,p in scores[:20]:
  shutil.copy(p, outdir/p.name)

print('selected',len(list(outdir.iterdir())))
```

실행:
```bash
python tools/clip_select.py
# 결과: out/selected/ 에 상위 매칭 이미지만 남음
```

## 팁(실전 적용)
- **CI에 고정 재현성**: ComfyUI 워크플로우를 API JSON으로 저장 + 시드 고정(노드 파라미터/파일명 메타)하면 동일 결과 재현 가능.
- **프롬프트 바꾸기**: `prompt='...'`만 교체해 즉시 다른 기준으로 재점수화.
- **성능**: CUDA가 있으면 수백 장도 빠르게 스코어링. 없으면 CPU로도 동작(시간만 더 소요).
- **폴더 구조**: `out/comfy/batches`(원본) → `out/selected`(선별본). 다운스트림(스프라이트 슬라이싱/리깅) 파이프에 바로 연결.

원하면 이 흐름을 **야간 배치(cron/GitHub Actions)** 템플릿으로도 바로 묶어 드릴게요.
