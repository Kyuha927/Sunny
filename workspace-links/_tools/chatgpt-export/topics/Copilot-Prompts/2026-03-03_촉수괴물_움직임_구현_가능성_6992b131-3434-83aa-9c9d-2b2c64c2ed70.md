Wan2.2 템플릿에서는 **프레임 수(`length`)를 조절하는 노드가 보통 따로** 있습니다(예: `EmptyHunyuanLatentVideo` 또는 5B 템플릿의 `Wan22ImageToVideoLatent`에서 `length`). citeturn4view0turn3view0  
FLF2V 템플릿에 `length`가 직접 보이지 않으면 아래 중 하나로 맞추면 됩니다.

- **(권장)** 템플릿 안에 `length`가 있으면: **24~32프레임**으로 설정  
  - 출력 인코더의 FPS가 16이면: 24f ≈ 1.5초, 32f ≈ 2초  
  - FPS가 24이면: 24f = 1초, 48f = 2초  
- `length`가 없다면: **기본 길이로 생성 → 편집에서 1~2초로 컷 편집**

### 4) 프롬프트 예시 (애니 액션에 맞춘 안정형)
**Positive(예시)**  
- `anime style, clean lineart, cel shading, high quality 2D animation frame, tentacle monster, dynamic action, aggressive lunge, tentacles extend forward toward camera, speed lines, impact feeling, dramatic lighting, static camera, simple background`

**Negative(예시)**  
- `photorealistic, 3d, live action, extra tentacles, extra limbs, duplicate, deformed, melted, bad anatomy, text, watermark, logo, flicker, jitter`

**촉수 전용 팁**  
- “촉수 개수”를 **정확히 박아두기**: `one main tentacle` 또는 `two tentacles only` 같은 식으로요.  
- 프레임마다 촉수가 증식하면 negative에 `extra tentacles, additional tentacles`를 강하게 넣습니다.

## B안: Wan2.1 Fun Control(Depth/Canny)로 “촉수 실루엣”을 컨트롤해서 공격 모션을 확정하기
촉수는 포즈(OpenPose)보다 **Depth / Canny(라인아트) / 스케치** 같은 **형태 신호로 강제하는 게 훨씬 안정적**입니다.  
Wan2.1 Fun Control은 Canny/Depth/OpenPose/MLSD/Trajectory 등 컨트롤을 지원하고, **16fps 기준 최대 81프레임(약 5초)**까지 가능합니다. citeturn3view3

### 1) 컨트롤 영상 만들기 (가장 간단한 방법)
당장 3D가 없어도 됩니다. 아래 중 아무거나 OK:

- **Canny용(추천)**: 흰 바탕에 검은색으로 촉수 라인만 그린 **2D 애니메이션(24~32프레임)**  
  - 프레임 0: 뒤에 웅크린 라인  
  - 프레임 중간: 반쯤 펼쳐지는 라인  
  - 마지막: 전방으로 뻗는 라인(끝이 카메라 쪽으로 크게)
- **Depth용(더 강력)**: 가까운 촉수는 밝게, 먼 촉수는 어둡게 칠한 “거리감” 애니메이션

### 2) ComfyUI 템플릿/입력 포인트
ComfyUI 공식 튜토리얼 기준으로 Fun Control 네이티브 워크플로우는 “컨트롤 비디오”를 넣어 돌리며, **네이티브만 쓰면 mp4 대신 WebP 비디오를 `Load Image`로 넣는 방식**을 사용합니다(현재 `Load Image`가 mp4를 지원하지 않는 제약). citeturn1view1  
mp4를 그대로 쓰고 싶으면 **VideoHelperSuite 같은 커스텀 노드 워크플로우 버전**을 쓰는 쪽이 편합니다. citeturn1view1

또 한 가지 중요 포인트:
- `WanFunControlToVideo`에 넣는 **프레임 수는 컨트롤 영상 프레임 수와 같아야** 합니다.  
  프레임 수가 더 길면 뒤쪽 프레임이 컨트롤에서 벗어날 수 있다고 안내되어 있어요. citeturn1view1

### 3) Fun Control에서 추천 설정(이 컷 기준)
- **해상도**: 처음엔 512 또는 768 계열로 작게(성공률/속도↑), 잘 나오면 업스케일
- **프레임 수**: 24~32 (1~2초에 딱 맞음, 16fps 기준) citeturn3view3
- **컨트롤 타입**: 촉수는 보통 **Canny 또는 Depth**가 안정적  
- **프롬프트는 “디자인/스타일 고정용”으로 짧고 강하게**  
  (모션은 컨트롤 영상이 담당)

예시 프롬프트:
- `anime, cel shading, tentacle monster, (same character design), static camera, dark alley background, dramatic rim light, action scene`
- negative는 A안과 동일하게

### 4) 후처리로 “애니처럼 매끈하게”
Fun Control 파이프라인 예시들에는 **프레임 보간(FILM VFI)**으로 더 부드럽게 만들고, 업스케일 후 최종 렌더까지 이어가는 구성이 자주 들어갑니다. citeturn5view0  
1~2초 짧은 컷은 특히 보간이 체감이 커요(짧은 시간에 “툭” 튀는 프레임이 눈에 띄기 때문).

## VRAM이 걱정이면
- Wan2.2는 **5B TI2V 템플릿이 “8GB VRAM + 네이티브 오프로딩”에 맞을 수 있다**고 공식 문서에 명시돼 있습니다. citeturn3view0  
- 다만 5B는 “통제력”보다는 “가벼움/접근성” 쪽이라, 촉수 모션을 확정하려면 결국 B안(컨트롤)이 더 강합니다.

## 추천 조합 (당장 결과 뽑는 순서)
1) **A안 FLF2V로 빠르게**: Start(웅크림) / End(뻗음) 2장만 잘 만들면 “공격 모션”이 꽤 그럴듯하게 나옵니다. citeturn4view0  
2) A안에서 촉수 모양이 프레임마다 흔들리면 → **B안으로 넘어가서 Canny 컨트롤 영상**을 넣어 실루엣을 고정합니다. citeturn3view3turn1view1
