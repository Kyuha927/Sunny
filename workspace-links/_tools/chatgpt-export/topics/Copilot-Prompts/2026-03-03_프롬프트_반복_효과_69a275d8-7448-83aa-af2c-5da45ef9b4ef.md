## 📘 논문 핵심 요약 — *Prompt Repetition Improves Non-Reasoning LLMs*

### 🧠 **무엇을 주장하는 논문인가?**
이 논문은 **단순히 입력 프롬프트(prompt)를 반복해서 넣는 것만으로도**, **추론(reasoning) 기능을 사용하지 않을 때** 대형 언어 모델(LLM)의 성능을 높일 수 있다고 보여줘. citeturn0search0

➡️ 즉,  
```
<질문/지시문>
```
대신  
```
<질문/지시문> <질문/지시문>
```
처럼 **2회 반복한 입력**을 주면 모델의 성능이 *상당히 좋아진다*는 거야. citeturn0search0

---

### 📊 **실험 결과**
논문에서 7개의 서로 다른 LLM(예: Gemini, GPT-4o, Claude, Deepseek 등)에 대해 비추론(non-reasoning) 모드에서 프롬프트 반복을 시험했는데:

✅ **총 70개의 모델×벤치마크 조합에서,  
47번 성능이 향상되었고, 0번도 악화되지 않았다.** citeturn0search1

특히 옵션이 먼저 나오는 문제(예: 객관식 테스트) 같은 경우에는 반복을 통해 *질문 맥락을 더 잘 반영할 수 있어 큰 효과*를 냈다고 해. citeturn0search1

📌 예시: 한 테스트에서는 **정확도가 21.33%에서 97.33%로 폭발적으로 상승**했다는 보도도 나왔어. citeturn0search10

### ⚙️ **왜 성능이 좋아질까?**
논문과 관련 해설들은 다음과 같은 **이유를 제시하고 있어**:

🔹 대부분 LLM은 **Causal Attention(원방향 주의)** 구조여서, 앞 토큰만 보고 뒤의 의미를 유추해.  
🔹 하지만 프롬프트를 두 번 읽으면 **두 번째에서는 전체 문맥을 이미 알고 있어서**, 실제론 모델 내부적으로 *일종의 ‘양방향 정보 흐름(Bidirectional)* 느낌이 생긴다는 설명이 있어. citeturn0search6

즉, “같은 입력을 두 번 볼 기회”를 줘서 **모델이 더 정확하게 핵심을 파악하게 되는 거야**. citeturn0search9
