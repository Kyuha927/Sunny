## 1. 유튜브 영상 자동화 시스템 구축 및 활용
<mark>대본 입력만으로 이미지, 나레이션, 자막까지 포함된 영상을 5분 안에 완성하는 AI 자동화 시스템 구축 및 활용 방법을 안내한다.</mark>

### 1.1. 자동화 시스템 소개 및 필요성
1.  **유튜브 영상 제작의 어려움**: 대본 작성, 이미지 제작, 나레이션 녹음, 편집 등 영상 하나 제작에 최소 반나절 이상 소요된다.
2.  **AI 자동화 시스템의 등장**: '튜브젠 AI'는 대본 입력 시 AI가 어울리는 이미지를 생성하고, 나레이션 및 자막까지 자동으로 만들어 MP4 영상으로 내보내 준다.
3.  **시스템 공유**: 이 영상에서는 AI 자동화 시스템을 만드는 방법과 사용법을 공유한다.

### 1.2. 시스템 구축을 위한 사전 준비물
1.  **필수 설치 프로그램**:
    *   **VS Code**: 개발자들이 가장 많이 사용하는 코드 에디터이다.
    *   **Node.js**: 자바스크립트 프로그래밍 언어를 실행시키는 환경이다.
    *   **Claude Code**: 터미널에서 AI와 대화하며 코딩할 수 있는 도구이다.
2.  **API 키 발급**:
    *   **Gemini, ElevenLabs**: 각 서비스에서 API 키를 발급받아야 한다.
3.  **걱정 해소**: 설치 과정이 어렵게 느껴질 수 있으나, 단계별로 쉽게 따라 할 수 있도록 안내한다.

### 1.3. VS Code 및 Node.js 설치 (Mac 기준)
1.  **VS Code 설치**:
    *   VS Code를 검색하여 Visual Studio Code를 클릭한다.
    *   '다운로드 Mac OS'를 클릭하여 다운로드 후 설치한다.
2.  **Homebrew 설치**:
    *   Homebrew를 검색하여 맥주병 아이콘을 클릭한다.
    *   제공되는 명령어를 복사한다.
    *   터미널 창(Command + Space바 검색)에 붙여넣고 패스워드를 입력하여 설치한다.
3.  **Node.js 설치**:
    *   터미널에 `brew install node` 명령어를 입력하여 Node.js를 설치한다.
    *   `node -v` 및 `npm -v` 명령어로 설치 여부 및 버전을 확인할 수 있다.
4.  **VS Code 설정**:
    *   VS Code를 실행하고 '폴더 열기'를 클릭한다.
    *   제공되는 '025 자동화 콘텐츠' 폴더를 열어 실행한다.
    *   필요시 터미널 구간을 생성하거나 추가한다.

### 1.4. API 키 발급 및 설정
1.  **API 키의 역할**: 자동화 시스템의 다양한 기능을 연결하기 위해 필요하다.
2.  **필요 API 키**: Gemini와 ElevenLabs의 API 키를 발급받는다.
    *   ElevenLabs 구독이 부담스러운 경우, Gemini 키만 사용해도 되지만 음성 자동 생성 기능은 제한된다.
3.  **Gemini API 키 발급**:
    *   'Google AI Studio'에 접속하여 '새 프로젝트 만들기'를 진행한다.
    *   'API 키 만들기'를 클릭하여 키를 생성하고 복사한다.
    *   **무료 등급 사용**: Gemini는 약 90일간 300달러 상당의 무료 사용이 가능하므로, 카드 등록 후 무료 체험을 추천한다.
    *   발급받은 Gemini API 키를 VS Code의 Gemini API 키 입력란에 붙여넣는다.
4.  **ElevenLabs API 키 발급**:
    *   ElevenLabs 웹사이트에 접속하여 로그인한다.
    *   'Developers' 메뉴에서 'Create API Key'를 클릭한다.
    *   'Create Key'를 누르기 전, 'Access'를 모두 체크한 후 키를 생성하고 복사한다.
    *   발급받은 ElevenLabs API 키를 VS Code의 ElevenLabs API 키 입력란에 붙여넣는다.
5.  **시스템 사용 준비 완료**: API 키 설정이 완료되면 시스템을 사용할 준비가 된 것이다.

### 1.5. 자동화 시스템 실행 및 기능 활용
1.  **서비스 실행**:
    *   API 키가 채워진 상태에서 '서비스 실행'을 클릭하거나, 터미널에서 실행한다.
    *   로컬 네트워크 주소(예: `localhost:8000`)가 표시되면 해당 주소를 클릭하여 AI 에이전트 인터페이스에 접속한다.
2.  **주요 기능**:
    *   **참조 이미지 설정**: 원하는 캐릭터 이미지나 화풍을 설정할 수 있다.
    *   **나레이션 음성 설정**: ElevenLabs API 키를 사용하면 다양한 음성 설정을 활용할 수 있다.
3.  **콘텐츠 생성 테스트**:
    *   '수동 대본' 입력란에 대본을 넣으면 이미지, 음성, 자막이 생성된다.
    *   생성된 영상은 MP4 및 자막 파일로 다운로드할 수 있다.
4.  **사용자 선택**:
    *   프로그램을 바로 사용하고 싶은 경우, 이 단계까지만 진행하면 된다.
    *   직접 시스템을 개발하고 싶은 경우, 다음 단계로 넘어간다.

### 1.6. 자동화 프로그램 직접 만들기 (Claude Code 활용)
1.  **개발 비용**:
    *   Gemini 이미지 생성 시 약 53원, 7,000자 기준 영상 제작 시 약 5,000~6,000원의 비용이 발생한다.
    *   이는 9시간 수동 작업 대비 효율적인 비용으로 볼 수 있다.
2.  **Claude Code 설치 및 설정**:
    *   VS Code에서 새로운 폴더('테스트 자동화')를 생성한다.
    *   제공되는 Claude Code 설치 파일을 다운로드하여 설치한다. (Mac/Linux: `curl -fsSL https://claude.ai/install.sh | bash`, Windows: `irm https://claude.ai/install.ps1 | iex`)
    *   **유료 사용 필수**: Claude Code는 토큰 소모량이 많아 반드시 유료로 사용해야 한다.
    *   설치 후 홈페이지에서 승인 버튼을 눌러 설치를 완료한다.
3.  **Claude Code 모델 선택**:
    *   'Opus' 모델 대신 'Default' 또는 'Sonnet' 모델 사용을 권장한다. Opus 모델은 토큰 소모가 많아 중간에 사용이 불가능해질 수 있다.
4.  **Claude Code의 역할**: 코딩을 대신해 주는 AI로, 사용자가 원하는 내용을 대화하듯 입력하면 코드를 생성해 준다.
5.  **프로젝트 생성 프롬프트**:
    *   **역할 정의**: "당신은 AI 시스템 아키텍처이자 자동화 전문가입니다." 와 같이 역할을 명확히 한다.
    *   **워크플로우 설명**: 대본 분할, 이미지 프롬프트 생성, 이미지 생성, TTS 생성, 자막 생성, MP4 렌더링 등 시스템의 전반적인 작동 과정을 상세히 설명한다.
    *   **초기 프롬프트**: 처음에는 "영상 자동화를 하고 싶어. 알려줘." 와 같이 간단하게 시작해도 된다.
    *   **플랜 모드 활용**: 프로젝트 초기 생성 시에는 '플랜 모드'를 사용하여 차근차근 만들어가는 것이 좋다.
6.  **프로그램 구현**:
    *   "파이프라인을 어떤 프로그래밍 언어로 구현할 수 있겠습니까? 추천해주세요." 와 같이 질문한다.
    *   웹 UI, Python 언어, Gemini 및 ElevenLabs API 키 사용, 유튜브 교육 영상 제작 등 조건을 명시한다.
    *   AI가 생성한 내용을 확인하고, 이해가 어렵다면 다른 AI에게 쉽게 설명해 달라고 요청할 수 있다.
    *   AI가 제시하는 작업 목록(기반 구조, 텍스트 처리, 미디어 생성 등)을 따라 프로그램을 구현한다.
7.  **API 키 저장소 설정**:
    *   `.env` 파일에 Gemini와 ElevenLabs API 키를 입력하고 저장한다. (Command/Ctrl + S)
8.  **서비스 실행 및 오류 수정**:
    *   서비스를 실행하고, 오류 발생 시 오류 메시지를 복사하여 AI에게 수정 요청을 한다. (예: "대본을 입력했더니 오류가 생겼어. 수정해줘.")
    *   AI와의 대화를 통해 오류를 수정하고 기능을 개선해 나간다.
9.  **기능 개선 및 커스터마이징**:
    *   화면 흔들림 수정, 필터 적용, 화풍 변경(2D 애니메이션 등) 등 원하는 대로 기능을 수정하고 추가할 수 있다.
10. **단톡방 운영**: 궁금한 점은 단톡방에서 질문하면 답변받을 수 있으며, 아이디어를 얻어 추가 영상을 제작할 예정이다.
11. **최종 결과 확인**: 수정된 시스템으로 영상을 생성하고 다운로드하여 결과를 확인한다.
12. **바이브 코딩 실력 향상**: 에러 수정, 기능 추가 등 AI와의 반복적인 대화를 통해 바이브 코딩 실력을 향상시킬 수 있다.
13. **초보자를 위한 조언**: 처음에는 어렵게 느껴질 수 있으나, 직접 시도해 보면 어렵지 않으며, 필요시 단톡방을 통해 도움을 받을 수 있다.
