여러 AI 조교가 **실제 직원처럼 대화하고 협업**하여 복잡한 작업을 병렬로 처리하는 '에이전트 팀' 기능을 소개합니다. 이 기능을 활용하면 **팀 리드가 조율하는 것처럼** 보고서 초안 작성, 퀴즈 출제 등 여러 단계를 동시에 진행하여 **작업 효율을 극대화**할 수 있습니다. 복잡한 프로젝트를 맡길 때, 각자의 역할을 수행하며 스스로 소통하는 이 새로운 AI 조직 구성을 통해 실질적인 업무 성과를 높이는 방법을 배울 수 있습니다.

## 1. 에이전트 팀 기능 소개 및 핵심 개념
<mark>에이전트 팀은 여러 AI 조교가 팀을 이루어 서로 대화하고 협업하며 작업을 병렬로 처리하는 기능이다.</mark>

### 1.1. 에이전트 팀의 정의와 작동 방식
1. **에이전트 팀**은 여러 **AI 직원(조교)**이 팀으로 동시에 일하는 기능이다.
2. 이는 마치 교수님이 여러 조교에게 각기 다른 업무(교환 작성, 실험 준비, 퀴즈 출제 등)를 동시에 맡기는 것과 유사하다.
3. 핵심은 **조교(에이전트)끼리 직접 대화하고 조율**할 수 있다는 점이다.
   1. 이는 실제 직원들이 서로 소통하며 작업하는 방식과 비슷하다.

### 1.2. 에이전트 팀의 주요 특징
1. **병렬 처리**: 여러 조교가 동시에 작업을 수행한다.
2. **직접 소통 및 조율**: 팀원 간 직접 대화 및 조율이 가능하다.
3. **공유 작업 목록**: 진행 상황을 파악할 수 있는 공유 작업 항목 목록이 존재한다.
4. **결과 종합**: **팀 리드**가 최종 결과를 종합한다.

### 1.3. 에이전트 팀 구성 요소
1. **팀 리드 (Team Lead)**:
   1. 팀 생성, 팀원 생성, 작업 조정을 담당하는 주 **클로드 코드 세션**이다.
2. **팀 메이츠 (Team Mates)**:
   1. 할당된 작업을 각각 수행하는 **별도의 클로드 코드 창(인스턴스)**이다.
3. **테스크 리스트 (Task List)**:
   1. 팀원이 가져와서 완료하는 **공유 작업 항목 목록**이다.
4. **메일박스 (Mailbox)**:
   1. 에이전트 간 통신을 위한 **메시징 시스템**이다.
   2. 이 통신 기능 덕분에 에이전트 커뮤니티(몰트북)가 생겨나고, 나아가 **에이전트 소사이어티**와 **에이전트 이코노미**로 발전할 수 있다.
5. **작동 방식 요약**: 팀 리드가 총괄하고, 팀 메이츠가 작업을 수행하며, 테스크 리스트와 메일박스로 소통한다.

## 2. 서브 에이전트와 에이전트 팀 비교 분석
<mark>에이전트 팀은 기존의 서브 에이전트와 달리 팀원 간 직접 소통이 가능하며, 복잡한 협업 작업에 더 적합하다.</mark>

### 2.1. 서브 에이전트의 특징
1. **생성 및 보고**: 메인 에이전트가 서브 에이전트를 생성하고 작업을 부여하며, 결과가 나오면 보고를 받아 최종 결과물을 만든다.
2. **결과 취합**: 메인 에이전트가 모든 결과를 취합하여 마무리한다.

### 2.2. 에이전트 팀의 특징 및 장점
1. **팀 구성 및 소통**: 메인 에이전트(팀 리드)가 팀을 생성하고 작업을 할당하지만, 팀원들끼리 **공유 작업 목록**을 통해 서로 소통하고 작업한다.
2. **상호 작용**: 팀원들끼리 직접 소통하고 작업하는 것이 가장 큰 장점이다.
3. **논의 기반 해결**: "같이 논의하면서 해결하자"는 개념이 에이전트 팀의 핵심이다.

### 2.3. 상세 비교: 서브 에이전트 vs 에이전트 팀
1. **컨텍스트 및 독립성**:
   1. 서브 에이전트: 자체 컨텍스트 윈도우를 가지며, 결과는 호출자(메인 에이전트)에게 모두 준다.
   2. 에이전트 팀: 완전히 독립적이다.
2. **커뮤니케이션**:
   1. 서브 에이전트: 결과를 **주 에이전트에게만 보고**한다 (몰아주기 방식).
   2. 에이전트 팀: 팀원들이 **직접 서로 메시지를 교환**한다.
3. **교정 및 조정**:
   1. 서브 에이전트: 주 에이전트가 모든 작업을 관리한다.
   2. 에이전트 팀: **자체 조정**을 통한 공유 작업 목록을 활용한다.
4. **적합한 용도**:
   1. 서브 에이전트: 결과만 중요하거나 간단한 작업에 적합하다.
   2. 에이전트 팀: **토론과 협업**이 필요하거나 **복잡한 작업**을 발전시켜야 할 때 적합하다.
5. **토큰 비용**:
   1. 서브 에이전트: 결과가 주 컨텍스트로 요약되어 반환되므로 비용이 비교적 낮다.
   2. 에이전트 팀: 각 팀원이 별도의 클로드 창을 띄워 작업하므로 토큰 비용이 높다.

## 3. 에이전트 팀 활성화 및 사용 방법
<mark>에이전트 팀 기능을 사용하려면 설정 파일 수정, 프로젝트 생성, 그리고 구체적인 프롬프트 작성이 필요하다.</mark>

### 3.1. 기능 활성화 및 준비 작업
1. **기능 활성화**:
   1. **`settings.json` 파일**에 특정 부분을 추가해야 기능을 켤 수 있다.
   2. 관련 튜토리얼 텍스트 파일 링크가 고정 댓글에 제공된다.
   3. 튜토리얼을 참고하여 JSON 파일 설정 및 윈도우에서 파일 생성 방법을 확인해야 한다.
   4. JSON 파일이 없다면 직접 생성하면 된다.

### 3.2. 에이전트 팀 생성 및 프롬프트 작성
1. **팀 생성**: 자연어로 팀 생성을 요청한다 (예: "에이전트 팀을 구성해 줘").
2. **팀원 역할 지정**: 필요한 조교 역할(예: 교환 작성 조교, 퀴즈 출제 조교)을 명시한다.
3. **프롬프트 팀 지침 활용**:
   1. 프롬프트 작성을 쉽게 하도록 **프롬프트 팀 지침**이 첨부되어 제공된다.
   2. 클로드, 제미나이, ChatGPT 등 사용하는 플랫폼에 맞게 **새 프로젝트**를 생성한다.
   3. 프로젝트 생성 시, 목표를 작성하고 제공된 텍스트 파일의 내용을 **운영 지침**으로 복사하여 넣는다.
4. **요청 예시**: 경영학과 교수에게 도움이 되는 조교 에이전트 팀을 만들어 달라고 요청했다.

### 3.3. 실제 작동 및 결과 확인
1. **프롬프트 적용**: 완성된 경영학과 교수를 위한 에이전트 팀 프롬프트를 클로드 코드에 입력한다.
2. **팀 구성 및 가동**:
   1. 클로드가 에이전트 팀 구성을 준비하고, 교환 조교, 출제 조교, 검수 조교 역할을 지정한다.
   2. 팀 리드가 주제(예: AI가 회사 경영에 미치는 영향)를 설정하면, 각 조교가 가동되며 **자기들끼리 학습 목표를 주고받는 등 소통**한다.
3. **최종 결과**: 모든 작업 완료 후, 최종 통합 문서 저장이 완료된다.
4. **산출물**: 교환 학습 목표, 핵심 개념, 사례, 슬라이드 구성, 시험 문항 등이 순식간에 생성되었다.
5. **평가**: 기존 서브 에이전트 개념보다 한 단계 더 나아간 개념이며, 엔트로픽이 에이전트 시대를 선도하고 있다.

## 4. 주의사항 및 전망
<mark>에이전트 팀은 강력하지만 비용이 높으므로 주의해야 하며, 이는 미래 AI 조직의 시작을 의미한다.</mark>

### 4.1. 사용 시 고려 사항
1. **비용**: 현재 에이전트 팀 기능은 **비용이 많이 든다** (API 사용 시).
2. **염두**: 에이전트 팀을 사용할 때는 높은 토큰 비용을 염두에 두어야 한다.

### 4.2. 미래 전망
1. **조직화된 AI**: 에이전트들이 모여 조직을 이루는 시대가 이미 도래했다.
2. **경제 시스템**: 향후 **소사이어티**와 **에이전트 이코노미**가 생길 것으로 예상된다.
3. **권장**: 이 기능을 꼭 사용해 보기를 권장한다.
