클로드 AI를 텔레그램에서 **비용과 보안 걱정 없이 무제한으로 원격 제어**하는 방법을 공개합니다. 이 봇은 과거 대화와 위치 정보까지 기억하며, 12만 개 스킬을 안전하게 설치해 웹사이트 제작부터 PC 진단까지 대신 처리해 줍니다. 지금 바로 설치 파일을 받아 **나만의 강력한 AI 비서**를 구축하고 업무 자동화의 신세계를 경험하세요.

## 1. 텔레그램 기반 클로드 AI 봇 '소놀봇' 소개 및 기능 시연
<mark>클로드 AI를 텔레그램에서 비용 및 보안 걱정 없이 무제한으로 원격 제어하는 '소놀봇'의 강력한 기능들을 소개하고 시연한다.</mark>

### 1.1. 소놀봇의 핵심 특징 및 작동 원리
1. **소놀봇은 텔레그램 기반의 AI 봇**이며, 일반 봇이 아닌 **사용자 컴퓨터와 통신**하도록 설계되었다.
2. 이 봇은 **클로드 코드**를 기반으로 작동하며, 사용자의 명령에 따라 컴퓨터에서 코드가 반응하여 작업을 수행한다.
3. **비용 및 보안 문제 해결**:
    1. 클로드 구독만으로 비용이 해결되어 **요금 폭탄 위험이 없다**.
    2. 클로드 코드 기반이므로 **보안 위험이 없다**.
4. **강력한 메모리 및 과거 대화 참조 기능**:
    1. **과거 24시간 대화**를 항상 참조할 수 있는 특별 시스템을 구축했다.
    2. **메모리 시스템**을 통해 지금까지 소놀봇과 나눈 대화 및 작업 내용을 기록하여, 필요시 스스로 검색하고 내용을 끌어올 수 있다.
    3. 이로 인해 클로드 코드가 **연구 기억 능력**을 갖추게 되어 클로드봇과 유사하게 작동한다.

### 1.2. 원격 제어 및 자동화 작업 시연
1. **카페 추천 및 웹사이트 제작/업로드 시연**:
    1. 텔레그램으로 **부산 해운대 카페 추천**을 요청했다.
    2. 추천 결과를 **웹사이트로 만들어 FTP로 업로드**하도록 지시했다.
    3. FTP 정보는 직접 제공하지 않고, **이전 대화 참조**를 통해 소놀봇이 스스로 정보를 찾도록 했다.
    4. 소놀봇은 과거 대화에서 **FTP 계정을 스스로 기억**하여 찾아냈다.
    5. 웹페이지 제작 후 FTP 업로드를 시도하는 도중, 사용자 개입으로 **구체적인 정보 추가 요청**을 반영했다.
    6. 완성된 웹사이트는 **204곳의 카페 조사 결과**와 추천 카페 세 곳의 정보(설명, 이벤트, 꿀팁, 링크, 정보 출처)를 포함했다.
2. **원격 제어의 이점**:
    1. 텔레그램을 통해 외부에서 클로드를 조작하여 **언제 어디서든 작업 요청이 가능**하다.
    2. 아이디어가 떠오르면 즉시 텔레그램으로 **바이브 코딩이나 구현 요청**이 가능하다.
3. **FTP 스킬 제작 및 무료 호스팅 활용**:
    1. FTP 업로드는 **FTP 스킬**을 통해 가능하며, 이 스킬 역시 소놀봇에게 제작을 부탁했다.
    2. 소놀봇은 **비밀번호 방식**과 **키 파일 기반** 두 가지 파일 업로드 스킬을 생성했다.
    3. 생성된 웹페이지는 **타움(Taum)의 무료 호스팅**에 FTP 스킬로 즉시 업로드되었다.

### 1.3. 멀티모달 및 시스템 진단 기능 시연
1. **이미지 분석 능력**:
    1. 텔레그램으로 사진을 올리면 소놀봇과 클로드 코드가 통신하여 이미지를 분석한다.
    2. **남산 타워** 이미지 분석 결과, 간략한 설명과 함께 이미지를 올바로 분석했음을 확인했다.
    3. 이는 텔레그램을 통해 이미지 첨부 후 **다양한 작업(심지어 영상 제작)**도 가능함을 의미한다.
2. **PC 시스템 진단**:
    1. 컴퓨터가 느려진 것 같아 **악성 프로그램 조사**를 요청했다.
    2. 소놀봇은 시스템 및 네트워크 연결을 분석하여 **템프 폴더의 다수 XML 파일**과 **크로스 EX 프로그램**을 속도 저하 원인으로 감지했다.
    3. 최종 결과로 특별한 문제는 없으나, **대량 XML 파일 삭제 정리**와 **크로스 EX 프로그램 제거**를 권장하는 보고서가 나왔다.
    4. 이 작업은 클로드 코드가 작동하지만, 클로드 코드의 안정성 덕분에 신뢰할 수 있다.
3. **반복 작업 및 위치 기반 정보 획득**:
    1. **삼성 주가를 5분마다 조사**하여 반복적으로 알림을 받는 작업이 가능하다.
    2. 텔레그램에서 **첨부 파일을 클릭하여 위치를 전송**하면, 소놀봇이 좌표를 클로드 코드에 보내 정확한 지점을 파악한다.
    3. 해당 위치에 대한 **날씨 정보**를 분석하여 알려주며, 주변 음식점 등 다양한 정보를 외부에서 폰으로 받을 수 있다.

## 2. 소놀봇 설치 및 고급 설정 방법
<mark>소놀봇 설치 파일 실행부터 텔레그램 토큰 및 사용자 ID 등록, 스케줄러 설정, 그리고 스킬 설치 보안 방식까지 설명한다.</mark>

### 2.1. 설치 파일 실행 및 필수 환경 확인
1. **설치 준비**: 제공된 폴더를 받아 명칭을 변경한 후 원하는 위치에 둔다.
2. **셋업 파일 실행**: 폴더 내의 **셋업 파일**을 더블 클릭하여 실행한다.
3. **자동 설치**: 셋업 파일이 필요한 모듈을 자동으로 설치한다.
4. **필수 사전 설치 환경**:
    1. **파이썬**이 컴퓨터에 이미 설치되어 있어야 한다.
    2. **클로드 코드**와 **노드 JS**도 이미 설치된 상태여야 한다.

### 2.2. 텔레그램 봇 설정 및 ID 등록
1. **봇 토큰 발급 (BotFather 사용)**:
    1. 셋업 진행 중 **텔레그램 봇 토큰** 입력을 요청받는다.
    2. 텔레그램에서 **BotFather**를 검색하여 채팅창에 접속한다.
    3. `/newbot`을 입력하고, **영문 이름**을 지정하며 이름 끝은 반드시 `BOT`으로 끝나야 한다.
    4. 이름 전달 후 발급받은 **액세스 토큰**을 CMD 창에 입력한다.
2. **사용자 ID 등록**:
    1. 다음 단계에서 **사용자 ID** 입력을 요청한다.
    2. 텔레그램에서 **Get My ID**를 검색하여 채팅창에 접속한 후 `/start`를 입력하여 **Your ID**를 복사한다.
    3. 복사한 ID를 CMD 창에 넣고 엔터를 누르면 설치가 완료된다.
3. **첫 대화 시도**: 텔레그램에서 생성한 봇 이름을 검색하여 접속한 후 **첫 번째 대화**를 시도하여 통신을 활성화한다.

### 2.3. 스케줄러 등록 및 작동 방식
1. **레지스터 스케줄러 실행**: 설치 완료 후 **레지스터 스케줄러** 파일을 실행해야 한다.
2. **두 가지 모드**:
    1. **백그라운드**: 눈에 보이지 않게 작동하며, 관리자 권한으로 실행 시 1분마다 텔레그램 메시지를 확인하고 응대한다.
    2. **포그라운드**: **크롬 창을 띄우는 등 눈에 보이는 작업**이 가능하다. 외부 요청 시 크롬 브라우저를 직접 띄워 작업을 수행한다.
3. **실행 권한**: 두 모드 모두 **반드시 관리자 권한으로 실행**해야 한다.

### 2.4. 다중 봇 운영 및 스킬 설치 보안
1. **다중 소놀봇 운영**:
    1. 여러 개의 소놀봇을 운영할 수 있으며, 폴더마다 다른 설정을 적용하면 각각이 **클로드 코드 기반의 에이전트**처럼 작동한다.
    2. (참고: 영상에서는 클로드 기반 2개와 코덱스 기반 1개의 소놀봇을 운영 중이었다.)
2. **스킬 검색 및 설치**:
    1. 소놀봇에서 스킬 설치 가능 여부를 확인하면, **12만 개**의 스킬을 찾아서 설치할 수 있다.
3. **강화된 스킬 보안 시스템**:
    1. **신뢰도 기반 자동 차단**: 스킬 설치 시 **스타 수가 적거나 신뢰할 수 없으면 설치를 차단**한다 (예: 별점 0점 스킬 설치 불가).
    2. **사용자 최종 승인 필수**: 스킬이 스스로 보안 검토 보고서를 제공하더라도, **사용자의 최종 승인**을 받아야만 설치가 가능하다.
    3. 이 방식으로 약 12만 개의 스킬을 원하는 만큼 안전하게 설치하여 사용할 수 있다.
