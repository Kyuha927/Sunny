## 오픈클로(OpenClaw) API 비용 절약 팁: 깃허브 코파일럿 활용
<mark>월 10달러의 깃허브 코파일럿 구독료만으로 오픈클로의 특정 AI 모델을 무제한 사용하는 구체적인 세팅 방법을 소개한다.</mark>

### 1. 오픈클로 API 비용 문제 및 해결책 제시
1. **오픈클로(OpenClaw) 사용 시 API 비용 부담**
   1. API를 사용해야 하며, 비용이 꽤 크다.
   2. 예를 들어, 재미나이 플래시(Funai Flash)를 잠깐 사용했는데 하루에 3,000원씩 발생했다.
2. **해결책: 월 10달러로 무제한 사용 가능**
   1. **깃허브 코파일럿(GitHub Copilot)** 구독(월 10달러)을 활용하는 방법이다.

### 2. 깃허브 코파일럿과 오픈클로 모델 연동 원리
1. **깃허브 코파일럿 구독 정보**
   1. 월 10달러 구독 시 500회 요청까지 가능하며, 특정 모델 사용이 가능하다.
2. **모델 차감 기준의 맹점 활용**
   1. 코딩 툴(에디팅 툴)에서 모델을 선택할 때, 모델별로 차감 기준이 다르다.
   2. 일부 모델은 3개씩 차감되거나 1개씩 차감된다.
   3. <mark>특정 모델 5개는 차감되지 않고 0개(빵개) 차감된다.</mark>
   4. 이 0개 차감 모델을 이용하면 오픈클로를 무제한으로 사용할 수 있다.

### 3. 오픈클로 무제한 사용 환경 및 테스트
1. **현재 사용 환경 구성**
   1. 오픈클로가 켜져 있으며, 텔레그램으로 커뮤니케이션하고 있다.
   2. 텔레그램으로 질문하면 답변이 오며, 이는 원격 미니 PC에 설치된 오픈클로와 연결된 상태이다.
2. **무제한 모델(5 Mini) 사용 시 요금 차감 확인**
   1. 깃허브 코파일럿 사용 현황(예: 50.2%)을 확인했을 때, 질문(너 오늘 뭐 했어?)에 답변을 받았다.
   2. 답변이 느린 것은 내 PC로 돌아와서 답변이 넘어오는 방식이기 때문이며, 이는 로컬 특화 AI의 장점이다.
   3. 답변 후 요금 사용량(50.2%)을 새로고침해도 **차감이 발생하지 않았다 (0% 차감)**.
   4. 이는 해당 모델이 요금을 먹이지 않는 모델이기 때문이다.

### 4. 무제한 모델 설정 및 유료 모델과의 비교 테스트
1. **모델 변경을 위한 설정 접근**
   1. 터미널을 열고 **클로드보 온보드(ClaudeBot Onboard)**에서 모델을 변경한다.
   2. 인증 시 **코파일럿으로 인증**하고 **깃허브 코파일럿 디바이스 로그**로 로그인해야 한다.
2. **무제한 모델(0개 차감) 선택**
   1. 로그인 후 모델 선택 시 깃허브 탭에서 모델 목록을 확인할 수 있다.
   2. 0으로 되어 있는 모델(예: 4.15 미니, 그록 등) 중에서 **파브 미니(Fave Mini)**가 가장 똑똑하여 이를 선택하는 것을 추천한다.
3. **유료 모델(Opus 4.5) 사용 시 요금 차감 확인**
   1. 설정 후 리스타트하여 가장 센 모델인 **오퍼스 4.5**로 변경했다.
   2. 오퍼스로 변경 후 질문했을 때, 답변이 오퍼스로 처리되었음을 확인했다.
   3. 오퍼스 사용 후 요금 사용량(50.2%)이 **50.06%로 올라가며 차감**되었다.
   4. 결론적으로, 오퍼스를 쓰면 요금이 차감되지만, **파브 미니는 요금이 차감되지 않는다.**

### 5. 효율적인 모델 병행 사용 노하우
1. **파브 미니의 한계와 병행 사용의 필요성**
   1. 파브 미니는 멍청하여(똘똘하지 않아) 계속 사용하기는 어렵다.
   2. 따라서 **파브 미니와 오퍼스를 병행**하여 사용하는 것을 추천한다.
2. **자동화된 모델 구성 예시**
   1. 기본적으로 루틴하게 돌리는 앱들은 **파브 미니**를 사용하도록 설정한다.
   2. 파브 미니 사용 시 아웃풋이 만족스럽지 않으면 AI가 스스로 판단하여 **오퍼스**로 재시도하도록 설정할 수 있다.
   3. 실제 설정 예시: 디폴트 모델을 파브 미니로 설정하고, 파브 미니 시도 실패 시 오퍼스로 재시도하도록 구성한다.
3. **파브 미니의 활용 가치**
   1. 파브 미니는 요약이나 간단한 코딩 작업에는 충분히 잘 작동한다.
   2. 빡센 작업이 아니라면, 이 방법을 통해 AI를 무제한으로 사용할 수 있다.

### 6. 결론 및 추천
1. **API 요금 부담 시 코파일럿 활용 추천**
   1. 오픈클로를 빡세게 사용하고 싶은데 API 요금이 부담된다면, 월 10달러로 무제한 사용하는 이 방법은 매우 **혜자스럽다**.
2. **마무리**
   1. 이 방법으로 오픈클로를 잘 이용해 보기를 추천한다.
   2. 영상이 현명한 소비에 도움이 되었기를 바란다.
