메이플스토리 월드 리메이크 작업 시 **AI와 대화하며 코드를 완성하는 '바이브 코딩'의 실전 방법**을 배울 수 있습니다. 제공된 기획 문서(.md)와 8가지 도구를 갖춘 MCP를 활용하여, **복잡한 스크립트 수정이나 기능 구현을 AI에게 요청하고 검토하는 구체적인 워크플로우**를 익힐 수 있습니다. 코딩 능력이 부족해도 AI의 도움으로 개발 방향을 빠르게 찾고 실제 기능을 적용하는 효율적인 방법을 얻어 가세요.

## 1. 바이브 코딩 개념 및 준비물 소개
<mark>AI와 대화하며 코드를 완성하는 '바이브 코딩'은 MD 파일과 8가지 도구를 가진 MCP를 활용하여 효율적으로 월드를 리메이크하는 방식이다.</mark>

### 1.1. 바이브 코딩의 정의와 한계
1. **바이브 코딩**은 원하는 기능을 AI가 초안 코드를 만들고, 대화를 통해 수정하여 최종 완성하는 코딩 방식이다.
   1. GPT나 Gemini와 같은 AI를 사용하여 대화를 통해 코딩하는 느낌을 준다.
2. **현재 AI의 코딩 실력은 100% 신뢰할 수 없다.**
   1. AI가 필요한 파일과 코드를 생성하지만, **얼추 맞을 뿐 수정이 필요**하다.
   2. 때때로 필요 없는 코드를 생성하기도 하므로, 어느 정도의 수정 작업은 필수적이다.

### 1.2. 리메이크 월드 개발 지원 도구 소개
1. **스크립트 주석의 한계**
   1. 스크립트의 주석은 함수 기능은 설명하지만, **기획이나 개발 방향**을 파악하기 어렵다.
2. **MD 파일 제공**
   1. 해당 월드의 **기획 내용을 MD 파일 형식**으로 정리하여 제공한다.
   2. 이 파일을 AI에게 넘겨주면, 기획 관련 질문에 대해 직접 찾는 것보다 빠르게 답변을 얻을 수 있다.
3. **MCP (Model Context Protocol) 제공**
   1. MCP는 AI가 지정된 권한 내에서 작업 환경의 도구, 파일, 명령에 안전하게 접근하여 실제 작업을 수행하게 하는 **표준 인터페이스**이다.
   2. 메이플스토리 월드에서는 **총 8가지 도구**를 가진 MCP를 지원한다.
   1. **엠루아 엔트리**: 엠루아 파일 작업 시 사용해야 할 도구를 안내한다.
   2. **엠루아 그래**: 엠루아 스크립트의 문법과 기본 규칙을 제공한다.
   3. **엠루아 가이드라인**: 필수 개념, 용어, 구조 보완 등 개발 가이드라인을 제공한다.
   4. **엠루아 API 리트리버**: 사용 가능한 API, 클래스, 함수 등의 상세 정보를 제공한다.
   5. **엠루아 도큐먼트 리트리버**: 개발 관련 구현 방법, 예제, 문제 해결 문서를 제공한다.
   6. **MSW help**: 월드 개발에 필요한 분류별 API 컴포넌트 가이드 분석을 제공한다.
   7. **루트**: MCP 서버의 루트 엔드포인트로 시스템 상태 및 기본 정보 확인에 사용된다.
   8. **헬스 체크 헬스 게시**: MCP 인스펙트에서 서버의 정상 작동 여부를 확인한다.

### 1.3. 바이브 코딩 워크플로우 개요
1. 리메이크 월드 크리에이터는 **MD 파일**과 **8가지 도구를 가진 MCP**를 지원받는다.
2. 이 두 가지를 활용하여 AI와 대화하며 코드를 작성하고 완료하는 **바이브 코딩**으로 월드를 리메이크할 수 있다.

## 2. VS Code 및 Copilot 설정
<mark>VS Code에서 Copilot을 설치하고 MCP 서버를 연결한 후, AI의 지침(Instruction)을 설정하여 개발 환경을 준비한다.</mark>

### 2.1. VS Code 환경 설정 및 Copilot 설치
1. 작업할 월드(예: 광부 시뮬레이터)를 **로컬 워크스페이스로 설정**해야 한다.
2. VS Code에서 **Copilot**을 검색하여 설치한다.

### 2.2. MCP 서버 연결
1. Copilot 설정 후, F1 키를 눌러 검색창을 연다.
2. `Add Server`를 검색하여 선택하고, **HTTP 방식**을 사용한다.
3. 해당 링크를 입력하고 서버 이름을 설정하면 연결이 완료된다.

### 2.3. AI 지침(Instruction) 설정
1. MCP를 잘 사용하기 위해 **톱니바퀴 아이콘**을 클릭하고 `Instructions`를 선택한다.
2. `New Instruction File`을 생성하고 이름을 `my_instruction`으로 지정한다.
3. 이 파일은 AI가 질문에 답변할 때 따라야 할 **지침**을 정의하는 역할을 한다.
4. **필수적으로 넣으면 좋은 지침**은 다음과 같다.
   1. `.mlua` 확장자 파일을 사용할 때 **메이플스토리 월드 MCP에서 제공하는 툴을 반드시 사용**하도록 명시한다.
   2. 작업 경로를 **`rootdesk/myDesk`로 지정**하여 AI가 다른 영역을 수정하는 것을 방지한다.
   3. 생성하는 `.mlua` 파일은 **지정된 경로 하위**에만 만들도록 지시한다.

### 2.4. 로컬 워크스페이스 사용 시 주의사항
1. 로컬 워크스페이스는 메이커와 달리 **이전 작업으로 돌아가는 기능(리비전)**을 지원하지 않는다.
2. 실수를 했을 때 이전 상태로 되돌릴 수 없는 상황에 대비해야 한다.
3. 이러한 상황을 대비하기 위해 **형상 관리(버전 관리)**를 사용하는 것이 좋다.

## 3. 바이브 코딩 실습: 기능 구현 및 수정
<mark>MD 파일과 MCP 도구를 활용하여 특정 기능(더블 점프, 함정 데미지, 기력 회복 속도)을 AI에게 요청하고 검토하여 수정하는 과정을 시연한다.</mark>

### 3.1. 파일 추천 및 코드 생성 요청
1. **기능 구현 파일 확인 요청**
   1. "더블 점프를 구현하고 싶은데 어떤 파일을 확인해야 하는가?"라고 질문한다.
   2. AI는 `PlayerController`, `Movement`, `PlayerInput` 등 **실제 파일들을 추천**한다.
2. **파일 첨부 및 코드 생성**
   1. 추천된 파일을 채팅창으로 끌어다 놓거나 **플러스 버튼**을 눌러 첨부한다.
   2. 두 파일을 첨부한 후, "이 두 파일에서 더블 점프를 구현해라"라고 명령한다.
   3. AI는 `Script_DoubleJump`라는 이름으로 프로퍼티까지 포함된 코드를 작성하여 보여준다.
3. **코드 검토 및 적용**
   1. AI가 작성한 코드를 **`Keep`**하거나 **`Undo`**할 수 있다.
   2. `Keep`을 누르고 저장한 후 리프레시하면, 해당 파일이 워크스페이스에 추가된다.
4. **결과 확인 및 검수 필요성 인지**
   1. AI가 작성한 대로 테스트해보니 **실제 더블 점프가 구현되지 않았다.**
   2. 따라서 AI가 작성한 코드는 **반드시 직접 확인하는 검수 과정**이 필요하다.

### 3.2. 특정 로직 위치 탐색 및 수정 요청
1. **함정 데미지 수정 위치 탐색**
   1. "광산 입장 후 함정 데미지를 수정하고 싶을 때 어떤 파일을 선택해야 하는가?"라고 질문한다.
   2. AI는 `Trap` 컴포넌트 내의 `Trap` 파일에 **데미지 부분이 있다**고 알려준다.
2. **기력 회복 속도 변경 요청**
   1. 시프트 대시 시 사용되는 **기력(MP) 회복 속도를 빠르게 변경**하도록 요청한다.
   2. `ExtendPlayerController` 파일을 추가하고 기력이 포함되어 있는지 질문했으나, 포함되어 있지 않다는 답변을 받는다.
   3. AI는 대시할 때 감소하는 값은 **MP**이며, 자세한 감소 로직은 `PlayerInGameData` 파일의 `UseMP` 함수에서 확인할 수 있다고 안내한다.
   4. 해당 파일에서 MP 회복이 `OnUpdate` 시 이루어지는 것을 확인하고, **회복 값(0.2)을 20으로 변경**한다.
   5. 테스트 결과, 기력이 **빠르게 회복**되는 것을 확인했다.

### 3.3. 추가 수정 및 결과 확인
1. **MD 파일 및 MCP 활용의 이점**
   1. MD 파일과 MCP가 없었다면 수많은 플레이어 관련 문서를 직접 찾아봐야 했을 것이다.
   2. 오늘 소개한 방법은 **수정하고 싶은 내용**을 질문하여 필요한 파일을 빠르게 찾아 수정까지 완료하는 효율성을 보여준다.
2. **대시 쿨타임 및 소모량 수정**
   1. 기력 회복 속도는 빨라졌으나 쿨타임이 그대로이므로, 쿨타임을 **0.1초로 줄이도록** 요청한다.
   2. AI는 프로퍼티 값을 수정하면 된다고 안내하며, **3초로 설정된 부분을 0.1초로 변경**하라고 지시한다.
   3. UI에 표시되는 부분과 혹시 모를 다른 파일들도 **0.1초로 변경**했는지 확인한다.
   4. 대시 시 **만화(기력) 소모량**도 1로 줄여 멀리 갈 수 있도록 수정한다.
   5. 테스트 결과, UI는 변경되지 않았으나 **거리 증가 및 소모량/회복량 수정이 완료**된 것을 확인했다.

## 4. 바이브 코딩의 효율성과 주의사항
<mark>MD 파일과 MCP를 활용한 바이브 코딩은 편리하지만, AI 코드에 대한 철저한 검수와 사용량 제한 확인이 필수적이다.</mark>

### 4.1. 바이브 코딩의 효율성
1. 짧은 시간 동안 대시 기력 회복량과 사용량을 수정하는 등 **편리하고 효율적인 작업**이 가능했다.
2. **한 화면에서 모든 작업**을 처리할 수 있어 편리하다.
3. API에 대한 질문에도 AI가 잘 대답해 준다.

### 4.2. 사용 시 주의사항
1. **AI가 작성한 코드는 완벽하지 않으므로 반드시 검수해야 한다.**
   1. AI 코드를 확인 후, **`Keep`**할 부분과 직접 수정하거나 삭제할 부분을 구분해야 한다.
2. **사용량 제한 확인**
   1. GPT나 Gemini와 마찬가지로 Copilot 사용에도 **제한량이 존재**한다.
   2. 작업 시 피해가 가지 않도록 본인이 사용하는 AI 모델의 제한량을 반드시 확인해야 한다.

### 4.3. 마무리
1. MCP와 MD 파일을 활용하여 메이플스토리 월드 리메이크를 쉽게 하는 방법을 소개했다.
2. 모든 리메이크 월드 크리에이터들이 원하는 대로 리메이크를 성공하기를 바란다.
