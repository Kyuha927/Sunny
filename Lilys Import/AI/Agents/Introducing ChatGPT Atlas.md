OpenAI가 공개한 **ChatGPT Atlas**는 단순한 웹 브라우저를 넘어, **AI 기반의 대화형 웹 경험**을 제공하는 혁신적인 도구입니다. 이 콘텐츠는 **'브라우저를 채팅으로 대화하는 경험'**으로 재정의하며, 사용자가 웹을 탐색하고 작업을 수행하는 방식을 근본적으로 바꿀 세 가지 핵심 기능, 즉 **'어디서든 따라오는 채팅', '브라우저 메모리', 그리고 '에이전트 모드'**를 구체적으로 소개합니다. 이 브라우저를 통해 복잡한 정보 검색이나 반복적인 업무를 ChatGPT와 함께 처리하며, 웹 사용의 생산성과 즐거움을 극대화하는 **실질적인 적용 방법**을 배울 수 있습니다.

## 1. ChatGPT Atlas 소개 및 브라우저의 재정의

OpenAI가 **ChatGPT Atlas**라는 새로운 웹 브라우저를 공개하였으며, 이는 AI 기반의 대화형 웹 경험을 제공하는 혁신적인 도구이다. 이 브라우저는 **'브라우저를 채팅으로 대화하는 경험'**으로 재정의하며, 기존의 URL 바나 검색창과 같은 아날로그를 넘어 미래의 인터넷 사용 방식이 될 것으로 기대된다.

### 1.1. ChatGPT Atlas의 개발 배경 및 목표

1. **새로운 브라우저의 비전**: ChatGPT Atlas는 ChatGPT를 중심으로 구축된 AI 기반 웹 브라우저이다.
2. **브라우저 혁신**: 지난 수십 년간 브라우저 혁신이 정체되었다고 판단하고, 브라우저가 무엇이 될 수 있는지 재고할 기회로 보았다.
3. **대화형 경험의 중요성**: 미래의 인터넷 사용 방식은 채팅 경험과 웹 브라우저가 결합된 형태가 될 것이라는 비전을 가지고 설계되었다.
4. **핵심 가치**: 브라우저가 이루어지는 곳에서 ChatGPT가 핵심적인 도움을 제공하여, 사용자가 페이지와 대화하고, 정보를 찾고, 에이전트 모드를 사용할 수 있게 한다.
5. **엔지니어링 리드 소개**: Ben이 Atlas의 엔지니어링 리드로서 소개되었다.
6. **경험의 재구상**: "브라우저와 대화할 수 있다면 어떨까?"라는 질문에서 시작하여, 복잡성과 혼란을 단순한 대화로 대체하며 경험을 재구상했다.
7. **ChatGPT의 역할**: ChatGPT가 Atlas의 **'심장부(beating heart)'**가 되도록 설계되어, 웹을 이동하는 동안 항상 곁에서 도움을 줄 준비가 되어 있다.
8. **사용자 경험 변화**: Atlas 사용 시 사용자가 더 호기심을 갖고 질문을 더 많이 하게 되어, 더 잘 알고 정보에 밝은 사람이 되도록 돕는다.
9. **성능 및 유연성**: Atlas는 놀라운 새로운 경험을 지원할 만큼 빠르고 유연하게 설계되었다.
10. **제품 리드 소개**: Adam이 Atlas의 제품 리드로서 소개되었다.

### 1.2. Atlas의 세 가지 핵심 기능 소개

1. **기존 기능 유지**: Atlas는 탭, 북마크, 비밀번호 자동 완성 등 사용자가 익숙한 모든 기능을 갖추고 있다.
2. **핵심 기능 개요**: Ryan이 곧 자세히 설명할 세 가지 특별한 핵심 기능이 존재한다.
3. **첫 번째 기능: 어디서든 따라오는 채팅 (Chat Anywhere)**
  1. 사용자가 웹에서 작업할 때 탭 간에 복사/붙여넣기를 할 필요가 없어진다.
  2. 웹사이트를 열어두면, 호출 시 채팅이 바로 나타나며 현재 작업 중인 내용에 대한 **맥락**을 가지고 더 유용하게 도움을 줄 수 있다.
4. **두 번째 기능: 브라우저 메모리 (Browser Memory)**
  1. 메모리는 ChatGPT에서 사용자들이 사랑하는 매우 중요한 기능이다.
  2. 사용자가 ChatGPT를 더 많이 사용할수록 개인화되고 더 잘 이해하게 되는데, 이 기능이 Atlas에서 웹 전반에 걸쳐 적용되어 사용자에게 더 개인화되고 도움이 된다.
5. **세 번째 기능: 에이전트 모드 (Agent Mode)**
  1. Justin이 시연할 예정이며, ChatGPT가 사용자를 대신하여 **행동(actions)**을 취할 수 있게 된다.
  2. 에이전트가 커서를 띄우고 사용자가 요청할 때 클릭하며, 예약이나 항공편 예약, 문서 편집 등을 도울 수 있다.
6. **시연 시작**: 제품 리드인 Ryan이 Atlas의 핵심 흐름 시연을 시작한다.

## 2. ChatGPT Atlas의 핵심 흐름 시연 (Ryan)

### 2.1. 홈 화면 경험 및 브라우저 메모리 활용

1. **홈 화면**: 앱을 처음 다운로드하거나 새 탭을 만들 때 나타나는 화면으로, 전통적인 브라우저와 유사한 경험을 제공하면서 ChatGPT의 모든 기능을 내장하고 있다.
2. **중앙 컴포저**: 화면 중앙에 질문을 할 수 있는 컴포저가 있으며, 도구, 모델, 채팅 기록이 있는 사이드바에 접근할 수 있다.
3. **브라우저 기능 활용**:
  1. **URL 이동**: "hacker news"를 입력하면 채팅이 해당 URL로 이동시킨다.
  2. **북마크 참조**: 인간 언어로 북마크를 참조하면 해당 Galaxy diff의 커밋을 열 수 있다.
  3. **웹 기록 검색**: 브라우저 메모리를 사용하여 이전에 봤지만 정확히 어디 있는지 모르는 문서를 검색할 수 있다. (예: "Atlas Core Design에 대한 문서 검색")
4. **개인화된 제안**: 컴포저 아래에 **제안(suggestions)**이 표시되며, 이는 Atlas가 사용자의 활동이나 다음에 하려는 작업을 이해하여 생성하는 개인화의 첫 번째 버전이다.
5. **제안의 발전**: 관심 있을 만한 뉴스 기사부터 사용자를 대신해 작업을 위임하는 에이전트 작업까지 다양하며, Atlas를 더 많이 사용할수록 제안이 더 좋아진다.

### 2.2. 웹사이트 내 사이드 채팅 (Ask ChatGPT Button)

1. **기능 접근**: GitHub 예시로 이동하여 아침에 작업하던 셰이더 코드를 보여준다.
2. **버튼 활성화**: 방문하는 모든 웹사이트 상단 우측에 있는 **'Ask ChatGPT' 버튼**을 클릭하면 **컴패니언 사이드바**가 생성된다.
3. **맥락 이해**: 이 사이드바는 ChatGPT가 할 수 있는 모든 것을 수행하지만, **특정 웹 페이지의 내용**을 볼 수 있다.
4. **사용성 변화**: 브라우저가 정보를 표시하는 도구에서 정보를 이해하고 경우에 따라 편집까지 해주는 도구로 변화하는 주요한 잠금 해제(unlock)가 되었다.
5. **예시: 코드 요약**: 현재 보고 있는 diff의 내용을 요약해달라고 요청할 수 있다.
6. **위험성 판단 요청**: "이것을 오늘 출시되는 RC에 안전하게 포함해도 되는가?"라고 질문하자, 에이전트는 **'낮은 위험(low risk)'**이라고 판단했다.
7. **다양한 활용**: 제품 비교, Pull Request 요약, Slack 채널 요약 등 광범위하게 사용할 수 있으며, 사용자가 더 많은 질문을 하도록 유도한다.
8. **패러다임 전환**: 단일 응답에서 벗어나 원하는 것을 얻을 때까지 계속해서 **워크숍(workshopping)**할 수 있는 방식으로 전환된다.

### 2.3. 검색 경험의 업그레이드

1. **검색 흐름**: 영화를 검색하는 예를 통해 Atlas에서 접근할 때 검색 기능이 크게 업그레이드되었음을 보여준다.
2. **LLM의 한계 극복**: 키워드 기반의 짧은 검색에서 LLM이 맥락 부족으로 어려움을 겪는 문제를 해결하고자 했다.
3. **탭 기반 전환**: Atlas 내에서 검색 시 상단에 탭이 생겨, **전통적인 검색 엔진**처럼 이미지, 비디오, 뉴스 기사 탭으로 빠르게 전환할 수 있으며, 홈 탭의 핵심 채팅 경험은 유지된다.
4. **링크 클릭 시 동작**: 검색 결과에서 링크를 클릭하면 기본적으로 채팅이 옆으로 밀리면서 웹이 **분할 보기(split view)**로 열린다.
  1. 원치 않으면 명령(Command) 클릭하거나 'Ask ChatGPT' 버튼을 닫을 수 있다.
  2. 이는 인터넷을 검색할 때 **동반자(companion)**가 있는 듯한 느낌을 준다.
5. **검색 결과와의 대화**: 리뷰 요약을 5단어 이하로 요청하는 등, 검색 결과와 **지속적인 주고받음(back and forth)**이 가능해져 웹페이지로 바로 보내지는 대신 다중 경험(multi experience)을 제공한다.

### 2.4. 커서 채팅 (Cursor Chat)을 통한 인라인 편집

1. **기존의 비효율적 흐름**: 이메일 초안 작성 시, 텍스트를 복사하여 ChatGPT로 가져가 톤이나 문법을 수정한 후, 다시 원본 위치에 붙여넣는 과정이 필요했다.
2. **Atlas의 개선**: Atlas는 이 흐름을 인터넷의 **모든 폼 필드나 텍스트 상자에서 인라인으로** 수행할 수 있도록 평탄화했다.
3. **인라인 편집 시연**: 이메일 텍스트를 선택하고 **ChatGPT 놉(nub)**을 누른 후 "언어를 다듬어 달라(tidy my language)"고 요청한다.
4. **결과 적용**: 편집된 텍스트로 선택된 부분이 **인라인으로 대체**되며, 이는 **범위가 지정된 편집(scoped edits)**을 매우 유용하게 수행할 수 있게 한다.
5. **명칭**: 이 기능을 **커서 채팅(Cursor Chat)**이라고 부른다.
6. **이메일 전송**: 수정된 내용을 확인한 후 이메일을 전송한다.

## 3. 에이전트 모드 시연 및 안전성 논의

### 3.1. 에이전트 모드 소개 및 준비 작업

1. **브라우저 품질**: ChatGPT 통합 외에도 Atlas는 전반적으로 부드럽고 빠르며 사용하기 좋은 훌륭한 브라우저이다.
2. **에이전트 모드 소개**: Pranav, Justin, Will이 에이전트 모드를 시연하기 위해 합류했다.
3. **에이전트의 활용**: 관심 없는 작업을 위임하거나, 이전에 본 적 없는 소프트웨어 사용법을 배우는 데 사용할 수 있다.
4. **에이전트의 강력함**: 에이전트가 사용자의 브라우저와 개인 인터넷에 완전히 접근할 수 있어 매우 강력하다.
5. **안전성**: 강력한 기능으로 인해 안전성이 중요하며, 모델부터 제품 경험까지 스택의 모든 부분에 안전 장치가 내장되어 있다.
6. **시연 시나리오**: 프로젝트 관리 경험이 없는 사용자가 유령의 집(haunted house) 계획을 위해 Google Doc을 사용 중이다.
7. **해결해야 할 문제**:
  1. 일부 사람들이 이번 주 할 일을 아직 채우지 않았다.
  2. Google Docs의 작업을 **Linear**라는 공식적인 작업 관리 소프트웨어로 변환하여 Linear 이슈로 만들고 싶다.
8. **위임**: 사용자는 프로젝트 관리 경험이 부족하므로, **에이전트 모드**를 클릭하여 이 작업을 위임한다.
9. **에이전트 활성화**: 에이전트 모드를 켜면 ChatGPT에게 Atlas 내에서 **사용자 대신 행동(take actions)**하도록 지시하는 것이다.
10. **에이전트의 동작**: 에이전트는 사용자처럼 보이는 자체 커서를 가지고 클릭하며, 사용자의 **로컬 인증 및 모든 기록**에 접근한다.

### 3.2. 에이전트의 작업 수행 및 협업

1. **신뢰 구축**: 팀은 에이전트가 무엇을 하는지 정확히 볼 수 있도록 제품 경험에 많은 주의를 기울여 신뢰를 구축하고자 했다.
2. **작업 진행**: 에이전트가 작업을 시작하는 것이 보이며, 사용자는 에이전트가 백그라운드에서 작업을 수행하는 동안 다른 작업을 할 수 있다.
3. **개인 생활에서의 활용 (레시피)**: 팟럭(potluck)을 계획하며 레시피 페이지에서 8인분 기준으로 필요한 재료를 계산하고 쇼핑 목록을 정리해달라고 요청한다.
4. **쇼핑 목록 주문**: "고기와 채소를 나를 위해 주문해 달라"고 요청하자, 에이전트는 사용자가 **Safeway**에서 **Instacart**를 통해 쇼핑하는 것을 선호한다는 것을 알고 Instacart로 이동하여 장바구니에 항목을 추가하기 시작한다.
5. **안전성 및 통제**:
  1. 브라우저를 공유하는 강력한 기능에는 **새로운 종류의 위험**이 따른다.
  2. **내장된 안전 장치**: ChatGPT 에이전트는 **사용자의 탭 내에서만** 작동하며, 컴퓨터에서 코드를 실행하거나 다른 파일에 접근할 수 없다.
  3. **사용자 통제**: 사용자는 에이전트에게 **로그인 상태 또는 로그아웃 상태**로 접근할지 여부를 결정할 수 있으며, 작업에 따라 신중하게 결정할 것을 권장한다.
6. **브라우저 메모리 옵션**: 브라우저 메모리 및 관련 제안 기능은 **완전히 선택 사항**이며, 설정에서 관리하거나 시크릿 창을 사용하여 기억되지 않도록 할 수 있다.

### 3.3. 작업 완료 확인 및 결론

1. **Instacart 주문 확인**: 약 2분 만에 에이전트가 장바구니를 채웠으며, 구매 결정은 사용자가 검토 후 내릴 수 있도록 구매 주문까지는 진행하지 않는 것이 더 낫다.
2. **Linear 작업 확인**: 에이전트가 Linear에 작업을 성공적으로 추가했으며, 각 작업에 대해 **적절한 사람들을 태그**했다.
3. **작업 탭 확인**: 에이전트가 작업한 탭(Google Doc)을 확인해보니, 할 일이 있는 사람들에게 **정중한 알림**을 남겨두었다.
4. **미래 비전**: 이러한 제어 및 위임 능력은 장기적으로 **'바이브 라이프(vibe lifing)'**를 위한 놀라운 도구가 될 것이며, 개인적 및 전문적 삶의 모든 종류의 작업을 에이전트에게 위임할 수 있게 된다.

2. **에이전트 모드 접근**: 에이전트 모드는 현재 **Plus 및 Pro 사용자**에게만 제공된다.
