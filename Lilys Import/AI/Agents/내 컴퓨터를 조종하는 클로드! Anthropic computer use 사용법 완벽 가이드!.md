AI가 직접 마우스와 키보드를 조작해 컴퓨터 작업을 수행하는 **미래형 컴퓨터 사용법**을 미리 체험할 수 있습니다. 이 기술은 스크린샷을 분석해 커서 이동, 클릭, 텍스트 입력까지 해내며, **실제 에이전트의 작동 원리**를 구체적인 데모를 통해 이해하게 해줍니다. 아직 초기 단계지만, 앞으로 업무 자동화의 가능성을 엿보고 싶은 분들에게 필수적인 시연입니다.

## 1. 클로드 컴퓨터 사용 기능(Computer Use) 소개
<mark>AI가 사람처럼 컴퓨터를 조작하는 새로운 기능인 '컴퓨터 사용 기능'을 소개하고 초기 성능을 설명한다.</mark>
### 1.1. 컴퓨터 사용 기능 개요
1. **컴퓨터 사용 기능**은 **AI를 통해 컴퓨터를 조작**할 수 있는 기능이다.
2. 이 기능은 **API 엔트로픽**에서 제공하는 데모를 통해 사용 가능하다.
3. 이는 **베타 버전**이며, AI가 사람처럼 커서 이동, 클릭, 텍스트 입력 등을 수행할 수 있다.

### 1.2. 초기 성능 및 한계
1. **OS 월드 평가**는 AI 모델의 컴퓨터 사용 능력을 평가하는 테스트이다.
2. 스크린샷 기반 테스트에서 **14.9%**의 성공률을 기록했는데, 이는 다음으로 높은 AI 시스템(7.8%)보다 훨씬 높은 수치이다.
3. 여러 단계로 작업을 수행했을 때는 **22%**의 성능을 기록했다.
4. 현재는 **실험적인 단계**로, 스크롤링이나 확대/축소 등에서 한계가 존재한다.

## 2. 컴퓨터 사용 기능의 작동 원리
<mark>컴퓨터 사용 기능이 스크린샷과 도구를 활용하여 컴퓨터를 조작하는 메커니즘을 설명한다.</mark>
### 2.1. 도구 및 입력 구조
1. 사용을 위해서는 **툴스 컴퓨터**라는 도구가 사용된다.
2. 이 도구에 현재 **디스플레이의 너비와 높이**를 함께 전송한다.
3. 제공되는 도구의 예시로는 **스트링 리플레이스 에디터** (텍스트 조작)와 **배시 커맨드** (명령어 실행)가 있다.
4. 컴퓨터 도구와 **스크린샷**을 보내면, 클로드가 이를 바탕으로 **어떤 액션을 취할지 응답**한다.

### 2.2. 조작 및 좌표 활용
1. 클로드의 응답에는 **좌표**가 포함되어 있다.
2. 이 좌표를 활용하여 컴퓨터를 **실제로 조작**할 수 있다.
3. 컴퓨터 사용 기능은 화면을 **픽셀 단위로 학습**하여 좌표 정보를 제공한다.

## 3. 컴퓨터 사용 기능 데모 실행 과정
<mark>실제 데모 환경을 구축하고, 틸 검색 및 비행기 비용 검색 작업을 수행하는 과정을 상세히 보여준다.</mark>
### 3.1. 환경 설정 및 준비
1. 데모는 **도커 파일**을 통해 사용 가능하도록 준비되어 있으며, 이를 실행하여 활용한다.
2. 사용을 위해서는 **도커 설치**가 필수적이다.
3. **API 키**가 필요하며, 이는 스픽 콘솔에서 생성하여 안전하게 저장해야 한다.
4. 준비된 키를 **파워셸**에서 환경 변수로 세팅한다.
5. 키 세팅 후, **`docker run` 명령어**를 사용하여 컨테이너를 만들고 실행한다.

### 3.2. 기본 조작 데모 (한글 폰트 설치 및 검색)
1. **로컬호스트 8080**에 접속하여 컴퓨터 사용 데모(우분투 환경)를 실행했다.
2. 한글이 깨지는 문제를 해결하기 위해 **한글 폰트**(`fonts-noto-cjk`)를 설치했다.
3. 구글에서 **'틸'**을 검색하도록 명령하자, AI가 스크린샷을 분석하여 파이어폭스 아이콘을 클릭해 브라우저를 실행했다.
4. AI는 **좌표**를 활용하여 마우스를 움직여 텍스트 리플레이스 도구로 '틸'을 입력했다.
5. 검색 결과가 화면에 표시되었으나, 현재 보이는 화면 정보만 알려주며 **스크롤링은 불가능**했다.
6. 텍스트 입력 시 **버그**가 있어 '틸트'를 입력해도 '틸'만 입력되는 문제가 있었으나, 곧 수정될 것으로 예상된다.
7. 이처럼 직접 폼을 입력하고 여러 조정을 할 수 있다.

### 3.3. 복합 작업 데모 (구글 플라이트 비행기 비용 검색)
1. **구글 플라이트**를 활용하여 뉴욕행 11월 2일에서 11월 25일 비행기 비용을 알아보도록 요청했다.
2. 작업 속도는 **느린 편**이다.
3. **레이트 리밋 에러**가 발생했는데, 이는 분당 실행 가능한 토큰 양을 초과했기 때문으로 추정된다.
4. "플리즈 컨티뉴"를 입력하여 재진행을 시도했으며, API 무료 사용 시 토큰이 빨리 소진되므로 **단계를 나누어 입력**하는 것이 좋다.
5. AI가 구글 플라이트를 통해 11월 20일 시작, 25일 귀국 요금을 성공적으로 찾아주었다.

## 4. 추가 작업 및 최종 평가
<mark>텍스트 파일 요약 작업을 수행하고, 현재 기술의 한계점과 미래 가능성에 대해 평가한다.</mark>
### 4.1. 텍스트 파일 요약 작업
1. **"하투 메이크 컴퓨터 유지.txt"** 파일을 요약하도록 요청했다.
2. 경로를 지정하고 **한글로 요약**해 달라고 요청하자, `cat` 명령어로 파일 내용을 가져와 요약했다.
3. 도커 컨테이너는 버그로 인해 정지 후 재시작이 안 되어, **컨테이너를 삭제 후 재실행**해야 했다.

### 4.2. 현재 한계점 및 미래 전망
1. 현재 이 기능은 **완벽하지 않으며** 초창기이므로 **분명한 한계**가 존재한다.
2. **비용**이 비싼 편이며, 데모에서 사용한 내용만으로도 약 1달러가 소요되었다.
3. 그럼에도 불구하고 **새로운 장이 열렸음**을 보여주며, **에이전트**의 작동을 체감할 수 있었다.
4. 앞으로 기술이 발전하여 새로운 에이전트들을 볼 수 있을 것으로 기대된다.
5. **소셜 네트워크에 사람처럼 올리는 행위** 등 오남용 가능성에 대해 엔트로픽 측에서 조치를 취해 놓은 상태이다.
6. 관심 있는 사용자들에게 활용을 권장하며 마무리한다.
