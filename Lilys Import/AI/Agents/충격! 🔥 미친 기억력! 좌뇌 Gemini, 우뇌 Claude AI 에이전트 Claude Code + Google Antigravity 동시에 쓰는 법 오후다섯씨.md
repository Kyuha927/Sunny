Antigravity 환경에서 Gemini와 Claude AI를 **'두 개의 뇌'처럼 동시에 활용**하는 방법을 배울 수 있습니다. 매번 같은 지시를 반복할 필요 없이, **심볼릭 링크를 이용해 AI의 장기 기억 장치(.md 파일)를 자동 동기화**하는 실용적인 팁을 얻어 AI 작업의 효율을 극대화하세요.

## 1. Antigravity 환경에서 AI 모델 활용 개요
<mark>Antigravity는 폴더 기반으로 AI 작업을 지원하며, Gemini와 Claude 모델을 동시에 활용하여 시너지를 낼 수 있다.</mark>
### 1.1. Antigravity 기본 작동 방식
1. **Antigravity**는 **폴더를 엑세스**하여 AI 작업을 수행하는 도구이다.
2. 사용자는 원하는 파일을 생성하고 변경하며 분석할 수 있다.
3. 처음 시작 시 **Open Folder**를 통해 작업할 폴더를 지정해야 한다.

### 1.2. 지원 모델 및 시너지 효과
1. **Gemini 모델**은 전체적인 **문맥 파악 및 정보 추출**에 강점이 있다.
2. **Claude Opus 4.5** 모델은 **디테일한 작업** 수행에 뛰어나며, 글쓰기 성능이 월등하다.
3. Gemini는 Claude에 비해 **컨텍스트 메모리가 두 배**이다.
4. 두 모델을 함께 사용하면 **시너지**가 발생하며, 이는 마치 **두 개의 뇌**를 사용하는 것과 같다.
   1. 오른쪽 뇌는 Gemini, 왼쪽 뇌는 Claude 역할을 수행한다.
   2. AI 모델들은 폴더 내 파일 생성, 글쓰기, 프로그래밍 등의 작업을 지원한다.

### 1.3. 파일 생성 및 저장 과정 시연
1. **피천득 스타일 수필 다섯 편 작성**을 Claude Opus 4.6 모델에 요청했다.
2. 초기에는 AI가 대화창에 글을 작성하려 했으나, 이는 잘못된 방식이다.
3. **Stop 버튼**을 눌러 중지 후, 다섯 편을 **각각 폴더에 파일로 저장**하도록 재요청했다.
4. 파일은 **.md (마크다운 포맷)**으로 폴더에 작성되며, **녹색 하이라이트**는 생성이 완료되었음을 의미한다.
5. 생성된 파일은 **승인(Accept)** 과정을 거쳐야 실제로 저장된다.
   1. 승인 대기 상태(ask any)일 때는 실제 파일로 반영되지 않는다.
   2. **All 버튼**을 누르거나 개별적으로 **Accept**하여 저장을 완료할 수 있다.

### 1.4. 파일 분석 및 모델 전환
1. 생성된 다섯 개 파일을 분석하도록 요청하자, **구조적 분석 결과**와 **핵심 문장 기법, 피천득 스타일** 등을 도출했다.
2. 분석은 기본적으로 **개별 파일 분석**으로 진행되지만, **다섯 개 파일의 연관성 분석**도 가능하다.
3. 현재 분석은 **Claude Opus 4.6 모델**로 수행되었으나, **언제든지 Gemini 모델로 즉시 변경**하여 작업을 이어갈 수 있다.
4. Antigravity는 **중재자 역할**을 하며, 모델(머리)과 기능(서포트)을 분리하여 지원한다.

### 1.5. Claude Code와 모델 독립성
1. Antigravity 인터페이스에는 **Claude 버튼**이 별도로 존재하며, 이를 누르면 **Claude Code**가 실행된다.
2. Antigravity 내의 Claude와 **Claude Code**는 **독립된 머리**에 해당한다.
3. Antigravity의 모델은 Gemini에게 **임대된 개념**이지만, Claude Code는 **사용자 컴퓨터에 로그인된 자신의 계정**으로 연결된다.
4. Claude Code 사용 시 **추가 비용 없이 구독 범위 내에서 할당량**을 사용할 수 있다.
5. Gemini 모델 역시 구글 AI 계정이 있다면 바로 사용할 수 있다.
6. 현재는 무료로도 두 모델 동시 활용이 가능하지만, Claude Code는 **프로 이상**에서만 사용 가능하다.

## 2. AI 에이전트 병렬 작업 및 관리
<mark>여러 AI 에이전트를 병렬로 생성하고, 에이전트 매니저를 통해 이들의 작업을 동시에 관리할 수 있다.</mark>
### 2.1. 장기 기억 장치(MD 파일)의 필요성
1. 새로운 세션(대화)이 시작되면 **이전 대화 기록이 사라지므로** 문맥 훈련이 필요하다.
2. 이 문제를 해결하기 위해 **장기 기억 장치** 역할을 하는 파일이 필수적이다.
3. **Claude.md**와 **Gemini.md** 파일이 이 역할을 수행한다.
   1. 이 파일들은 **프로젝트의 헌법이자 내비게이션**과 같다.

### 2.2. 에이전트 생성 및 병렬 처리
1. 장기 기억 장치를 통해 여러 **Claude Code 에이전트**를 동시에 실행(병렬 처리)할 수 있다.
2. **플러스(+) 버튼**을 눌러 **여러 에이전트**를 생성하고 각각 다른 일을 시킬 수 있다.
3. Gemini 모델을 사용하는 부분에서도 여러 **에이전트**를 무한정 추가할 수 있다.
4. 이 에이전트들은 공통적으로 알아야 할 메모리 정보(지시사항)를 **Claude.md**에 넣어 관리한다.

### 2.3. 오픈 에이전트 매니저 활용
1. **오픈 에이전트 매니저**는 Antigravity의 핵심 기능 중 하나로, 여러 에이전트를 강력하게 관리한다.
2. 매니저 화면에서는 현재 작업 중인 **워크스페이스**와 그 안의 **에이전트 개수**를 확인할 수 있다.
3. 새로운 에이전트를 추가하고 다른 작업을 요청할 수 있다.
   1. 예시로, 피천득 수필 에이전트와 별도로 **이광수 스타일 수필 작성 에이전트**를 추가했다.
4. 에이전트 매니저는 작업 진행 상황을 보여주며, 작업 완료 시 표시가 되거나 **사용자 승인**이 필요할 때 메시지를 띄운다.
5. 순차적 대화와 달리, 에이전트에게 요청하면 **결과물을 만들 때까지 기다릴 필요 없이** 다른 에이전트 작업을 바로 시작할 수 있다.
6. 모든 작업은 **'클로드 앤 구글' 폴더** 내에서 통합 관리된다.
7. 생성된 글들은 Claude Code를 활용하여 **분석 및 보완**할 수 있다.

## 3. 장기 기억 장치 동기화 및 설정 방법
<mark>Claude.md와 Gemini.md 파일의 내용을 동기화하여 두 AI 모델에 일관된 지시를 내리는 것이 중요하다.</mark>
### 3.1. Claude 사용 제한(리밋) 문제와 해결책
1. Claude는 **일일/주간 토큰 사용량 제한**이 있어, 과도하게 사용하면 사용이 잠길 수 있다.
2. 리밋에 걸렸을 경우, API를 사용하여 추가 비용을 지불하거나, **Gemini를 활용**하여 작업을 계속할 수 있다.
3. Gemini를 바로 쓸 수 있는 이유는 **장기 기억 장치인 Claude.md**를 미리 설정해 두었기 때문이다.

### 3.2. 장기 기억 장치(MD 파일)의 역할 확인
1. Gemini 모델에게 **새로운 세션 시작 시 무조건 읽게 되는 파일**이 무엇인지 질문했다.
2. 답변에 따르면, Claude에서는 **Claude.md**, Gemini에서는 **Gemini.md**가 해당 역할을 하며, 이름은 다르지만 **역할은 동일**하다.
3. 이 파일들은 AI 세션 시작 시 가장 먼저 읽는 **프로젝트의 헌법이자 내비게이션** 파일이다.
4. 두 파일에 **같은 내용**을 넣어두면, Claude와 Gemini 모두 **동일한 메모리(지시)**를 기반으로 작업을 수행한다.

### 3.3. 두 파일의 스마트한 동기화 방법
1. 매번 두 파일을 똑같이 만드는 것은 번거로우므로, **스마트하게 관리하는 방법**이 필요하다.
2. AI에게 두 파일을 항상 **싱크(동기화)** 맞추는 방법을 문의했다.
3. **가장 확실하고 관리가 필요 없는 방법**은 **심볼릭 링크(Symbolic Link)**를 사용하는 것이다.
   1. 심볼릭 링크는 **윈도우의 바로 가기보다 강력**하며, 프로그램 입장에서는 **똑같은 원본 파일**로 인식한다.
   2. 이 링크를 걸어두면 양쪽 AI 모두 **항상 같은 파일(쌍둥이)**로 인식한다.
   3. 두 AI를 모두 사용할 경우, 두 파일에 심볼릭 링크를 걸어달라고 요청하면 **자동으로 생성**해 준다.
4. **또 다른 방법**은 참조 형태로 구성하는 것이다.
   1. **Claude.md 파일**에 "Gemini.md를 항상 읽어라"는 명령어를 넣어두는 것이다.
   2. 이 경우 Gemini.md 파일만 관리하면 되고, Claude.md는 참조 형태로 구성된다.

### 3.4. Antigravity 활용의 편리성 및 마무리
1. **오픈 에이전트 매니저**는 다양한 워크스페이스와 에이전트 관리가 매우 편리하다.
2. 작업 중 관련된 텍스트를 매니저 내에서 **수정하거나 코멘트를 통해 보완**할 수 있다.
3. **Claude.md, Gemini.md**와 같은 장기 기억 장치를 활용하여 스마트하게 작업해야 한다.
4. 다음 시간에는 파일 기반 작업 시 유용한 **또 다른 도구**와 작성된 글을 관리하는 방법에 대해 설명할 예정이다.
5. 내용이 어려울 수 있으니 궁금한 점은 댓글로 문의하면 답변하겠다.
