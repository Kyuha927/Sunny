## 1. VS Code와 mLua 익스텐션 소개
<mark>VS Code와 mLua 익스텐션을 활용하여 메이플스토리 월드 개발 환경을 구축하는 방법을 소개한다.</mark>
### 1.1. VS Code 및 mLua 익스텐션 개요
1. **VS Code**는 코드 편집기이며, **mLua 익스텐션**은 VS Code에서 메이플스토리 월드 개발을 편리하게 돕는 확장 프로그램이다.
2. 외부 편집기에서 스크립트를 작성할 때 **mLua 문법**에 맞게 작성해야 하므로, VS Code에서 mLua 익스텐션을 사용하는 것이 좋다.
3. **mLua 언어**는 메이플스토리 월드 고유 언어로, 일반 루아 문법과 유사하지만 메이커 연동을 위한 추가 문법이 존재한다.
4. mLua 익스텐션을 사용하려면 월드가 **로컬 워크스페이스**로 설정되어 있어야 스크립팅이 가능하다.

## 2. mLua 익스텐션의 주요 기능: mLua 작성 지원
<mark>mLua 익스텐션은 파일 추가, 정의문 작성, 어트리뷰트 및 어노테이션 설정을 통해 mLua 스크립트 작성을 지원한다.</mark>
### 2.1. 파일 추가 및 정의문 작성
1. mLua 익스텐션을 사용하면 **mLua 파일**을 추가할 수 있다.
   1. **컴포넌트**나 **이벤트 타입** 파일을 추가할 수 있다.
2. **정의문** 작성이 가능하다.
   1. 메이커에서 사용하던 **프로퍼티, 메서드, 이벤트 핸들러, 익스텐드** 등의 기능을 정의할 수 있다.
   2. 익스텐션 사용 시 키보드만으로 정의문을 작성할 수 있으며, 컴포넌트의 **익스텐드**까지 정의 가능하다.

### 2.2. 어트리뷰트(Attribute) 설정
1. **어트리뷰트**는 사용 환경에 따라 의미가 다르며, 스크립트의 **동기화, 실행 제어, 최소/최대값** 등 다양한 속성을 설정한다.
2. mLua 익스텐션에서는 마우스 클릭 없이 **코드 작성만으로** 어트리뷰트를 설정할 수 있다.
   1. 어트리뷰트 사용 시 **골뱅이(@)** 기호를 사용한다.
3. **프로퍼티 동기화** 설정: `@sync`를 사용하여 프로퍼티 동기화를 정한다.
4. **메서드 실행 제어** 설정: 메서드 위에 `@`를 입력하고 실행 제어 공간을 지정한다.
   1. 실행 제어 공간은 괄호 안에 스트링으로 지정하며, 예시로 '클라이언트'를 설정할 수 있다.
5. **이벤트 핸들러 이벤트 샌더** 설정: 스트링 값에 변경할 대상을 적어 설정한다.
6. **프로퍼티 에디터 표시 관련 설정**
   1. **표시 여부 지정**: `@hideFromInspector`를 입력하면 메이커 프로퍼티 에디터에서 해당 프로퍼티가 보이지 않게 된다.
   2. **표시 이름 변경**: `@displayName`을 사용하고 스트링으로 표시할 이름을 지정하여 변경할 수 있다.
   3. **설명 추가**: `@description`을 사용하고 스트링으로 설명을 적으면 마우스를 올렸을 때 툴팁으로 나타난다.
7. **숫자형 프로퍼티 관련 설정**
   1. **최댓값 설정**: `@maxValue`를 사용하고 괄호 안에 정수형 최댓값을 지정한다.
   2. **최솟값 설정**: `@minValue`를 사용하고 괄호 안에 최소값을 지정한다.
   3. **간격 설정**: `@delta`를 사용하여 프로퍼티 에디터에서 좌우 버튼 이동 시 간격을 지정한다.
8. **문자열 프로퍼티 길이 제한**: `@maxLength`를 사용하여 입력 가능한 최대 글자 수를 지정한다.
9. **스크립트 타입 설정**: 스크립트 첫 줄에 골뱅이를 붙여 **컴포넌트, 로직, 이벤트, BT 노드, 스트럭트, 아이템** 등 스크립트 타입을 설정할 수 있다.

### 2.3. 어노테이션(Annotation) 기능
1. mLua 익스텐션에서도 메이커처럼 **어노테이션**을 사용할 수 있으며, `###` 후 `@` 버튼을 눌러 사용한다.
2. **타입 어노테이션**: `@any` 등을 사용하여 변수의 타입을 지정할 수 있다.
3. **파람 어노테이션**: `@param`을 사용하여 함수의 매개 변수 타입을 지정하여 스크립트 어시스트 도움을 받을 수 있다.
4. **리턴 어노테이션**: `@return`을 사용하여 함수나 메서드의 반환 타입을 지정할 수 있다.
5. **디스크립션 어노테이션**: `@description`을 사용하여 VS Code 툴팁에 표시할 설명문을 명시할 수 있다.
6. 이 외에도 `@deprecated` (사용하지 않음 표시)나 `@final` (오버라이드 방지 표시) 어노테이션을 사용할 수 있다.

## 3. mLua 익스텐션의 코드 편집 기능
<mark>mLua 익스텐션은 구문 강조, 코드 자동 완성, 코드 스니펫 등을 통해 코드 작성 편의성을 높인다.</mark>
### 3.1. 구문 강조 (Syntax Highlighting)
1. **구문 강조 기능**은 mLua의 구문을 분석하고 의미를 추론하여 색상을 입혀 가독성을 높인다.
   1. 주황색: **스트링 타입**
   2. 연두색: **타입**
   3. 하늘색: **어노테이션, 어트리뷰트**

### 3.2. 코드 자동 완성 (Code Completion)
1. **기본 자동 완성**: `self.` 입력 시 사용 가능한 심볼 후보를 보여주며, 일부만 입력해도 후보가 나타난다.
   1. 후보 목록은 `Ctrl + Space`로 다시 확인할 수 있다.
2. **엔티티/모델 ID 자동 완성**: 메이플스토리 월드를 분석하여 적합한 **엔티 ID**나 **모델 ID**를 컴플리션을 통해 보여준다.
3. **특수 인수 자동 완성**: 특정 인수(예: 이벤트 샌더, 실행 제어 공간)가 필요한 경우 `Ctrl + Enter`를 눌러 들어갈 수 있는 목록을 확인할 수 있다.
4. **코드 캐릭터 서포트**: 콤마(`,`), 점(`.`), 콜론(`:`) 사용 시 뒤에 입력 가능한 후보를 자동으로 완성해 주는 기능이다.
   1. 이 기능은 `Ctrl + Shift + X`를 통해 설정에서 켜거나 끌 수 있다.

### 3.3. 코드 스니펫 (Code Snippet)
1. **코드 스니펫**은 크리에이터가 사용하려는 코드의 **템플릿**을 제공하는 기능이다.
   1. 예시로 `C`만 입력해도 컴포넌트 템플릿이 나타난다.
2. **메서드 추가**: `ME` 입력 후 `2`를 치면 메서드 템플릿이 제공되며, `Enter`로 추가 후 `Tab`으로 반환 타입, 함수 이름, 매개 변수 등을 순차적으로 이동하며 설정할 수 있다.
3. **mLua 타입 스니펫**: 컴포넌트, 로직, 이벤트, BT 노드 등 **mLua 타입**을 자동으로 완성해 준다.
4. **클래스 멤버 스니펫**: 프로퍼티, 메서드, 핸들러 작성을 지원한다.

## 4. 코드 탐색 및 분석 기능
<mark>코드 작성 및 디버깅 시 사용되는 기능으로, 심볼의 참조 위치, 정의, 이름 변경 등을 지원한다.</mark>
### 4.1. 참조 및 정의 탐색
1. **Go to Reference**: 해당 심볼이 어디서 사용되는지 찾을 때 사용하며, 마우스 우클릭 또는 단축키 **Shift + F12**로 확인 가능하다.
2. **Find All References**: 해당 심볼의 **모든 참조**를 찾아 클릭 시 해당 위치로 이동한다. 단축키는 **Shift + Alt + F12**이다.
3. **Go to Definition**: 해당 심볼이 **어떻게 정의되었는지** 확인할 때 사용하며, 마우스 우클릭 또는 단축키 **F12**로 확인 가능하다.
4. **Go to Type Definition**: 해당 심볼의 **타입이 어떻게 정의되었는지** 확인할 때 사용한다.

### 4.2. 심볼 이름 변경 및 문서 탐색
1. **Rename Symbol**: 참조된 **모든 심볼의 이름을 한 번에 변경**할 수 있다.
   1. 변경할 심볼을 클릭 후 우클릭 또는 단축키 **F2**를 사용하여 이름을 변경한다.
2. **Document Symbol**: 문서 상단에서 현재 선택된 심볼을 표시하며, 클릭 시 **현재 문서 내 모든 심볼** 목록을 보여준다.
3. **개발자 센터 이동**: 심볼 클릭 후 **Open API Reference**를 클릭하면 해당 심볼의 메이플스토리 월드 개발자 센터 페이지로 이동한다.

## 5. 코드 어시스턴스 기능
<mark>코드를 더 쉽게 이해하고 작성하도록 돕는 기능들로, 심볼 정보 제공 및 함수 작성 지원을 포함한다.</mark>
### 5.1. 호버 및 인내 힌트
1. **호버 기능**: 심볼 위에 마우스를 올리면 해당 심볼의 **정보(타입, 이름, 사용 방식 등)**를 툴팁으로 제공한다.
2. **인내 힌트 (Inlay Hint)**: 멤버 오버라이딩 여부 및 개발에 도움이 되는 정보를 추가로 제공하며, 함수의 파라미터나 반환 타입이 명확하지 않을 때 정보를 추가해 준다.
3. **시그니처 헬퍼 (Signature Help)**: 함수 작성 시 함수에 반드시 포함되어야 하는 **시그니처(파라미터)**를 표시하여 작성을 돕는다.
   1. 오버로딩된 경우 방향키로 원하는 시그니처를 선택할 수 있다.
   2. `Ctrl + Shift + Space`로 시그니처 헬퍼를 다시 켤 수 있다.

## 6. 코드 오류 진단 및 설정/확장 기능
<mark>코드 오류 진단 기능과 익스텐션 설정, 파일 생성 기능 및 개발 시 주의사항을 다룬다.</mark>
### 6.1. 코드 오류 진단 기능
1. **문제 진단**: 상황에 따라 심각도에 따라 문제가 될 수 있는 부분을 진단한다.
2. 진단 결과는 우측 상단의 **토글 패널**을 활성화하여 **Problems** 창에서 확인할 수 있다.
3. **상시 분석의 한계**: 닫혀 있는 문서는 정상적으로 진단되지 않을 수 있으며, 문서를 활성화하면 즉시 분석하여 문제를 알려준다.

### 6.2. 설정 및 확장 기능
1. **mLua 익스텐션 설정**: 톱니바퀴 버튼을 통해 **Code Character Support**와 같은 익스텐션 세팅 값을 설정할 수 있다.
2. **콘텍스트 메뉴**: 왼쪽 탐색기 메뉴에서 마우스 클릭을 통해 원하는 타입의 **mLua 파일**을 생성할 수 있다.

## 7. mLua 사용 시 주의사항
<mark>메이커와 VS Code 간의 파일 동기화 문제와 이름 변경 시 제약 사항 등 개발 시 유의해야 할 점을 설명한다.</mark>
### 7.1. 동기화 필수 및 방법
1. 메이커와 mLua 익스텐션은 하나의 폴더를 공유하므로 **동기화 작업이 필수적**이며, 동기화가 안 될 경우 에러가 발생하거나 파일이 사라질 수 있다.
2. **메이커 → VS Code 동기화**: 메이커에서 **워크스페이스 → Refresh** 버튼을 눌러 수동으로 동기화해야 한다. VS Code에서 저장하면 VS Code에서는 별도 작업 없이 자동 반영된다.
3. **VS Code → 메이커 동기화**: VS Code에서 변경 후 저장하면 메이커에서 **Refresh** 버튼을 눌러야 변경 사항이 반영된다.
4. 자동 동기화가 안 될 경우 **로컬 워크스페이스 설정을 다시** 해봐야 한다.
5. **워크스페이스 메뉴 옵션**
   1. **Refresh**: 로컬 워크스페이스에서 변경점이 있는 파일만 메이커에서 새로 불러온다.
   2. **Reimport**: 개별 스크립트 또는 데이터셋 엔트리의 로컬 변경점을 메이커에 반영한다.
   3. **Reimport All**: 로컬 워크스페이스의 하이어라키와 **모든 파일**을 반영하며, 개별 파일 오류 시 시도하여 월드를 재로딩한다.

### 7.2. 이름 변경 제약 및 키워드 오류
1. **메이커 환경에서 스크립트 이름 변경 불가**: 메이커에서 수정 중일 때 VS Code에서 해당 스크립트 이름을 변경하면 **이름 불일치 오류**가 발생한다.
2. **키워드 오타**: 익스텐션에서 키워드를 잘못 입력한 상태로 메이커를 열고 **Refresh**를 누르면 **mLua 변환 중 오류** 팝업이 나타난다.
   1. 이후 mLua 창으로 돌아가면 잘못 입력한 키워드가 빨간색으로 표시된다.
