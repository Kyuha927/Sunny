맥에서만 사용 가능한 브라우저 자동화 도구들은 크게 빌트인 도구와 서드파티 앱 두 가지 범주로 나뉩니다.

빌트인 macOS 도구
Automator + Safari

macOS에 기본 내장된 Automator는 Safari와 연동해 웹페이지 열기, 폼 입력, 데이터 수집 등을 노코드로 자동화할 수 있습니다. AppleScript나 JavaScript for Automation(JXA)으로 확장도 가능하며, Finder, 터미널, Python 스크립트까지 함께 연동되어 복잡한 워크플로우 구성이 가능합니다.
reddit
+1

AppleScript + Safari

macOS 고유의 스크립팅 언어인 AppleScript로 Safari를 직접 제어할 수 있습니다. URL 이동, 쿠키 기반 세션 유지, JavaScript 실행(do JavaScript), 여러 프라이빗 창 동시 조작 등이 가능하며, 자신의 브라우저 세션과 쿠키를 그대로 사용하므로 Instagram, Facebook 같은 로그인이 필요한 사이트 스크래핑에도 유리합니다.
